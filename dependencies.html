Concept Dependency Map

This page shows which ideas should come before other ideas. Read it as a route for understanding, not as a ranking of importance.

Concept Learn First Why This Dependency Matters Confusion It Prevents
Physics-Informed Neural Networks
  • Partial Differential Equations
  • Deep Learning
  • Optimization For Learning
 A PINN combines a fitted neural network, a differential equation check, and a training score. Without the dependencies, a reader may think a PINN is a neural network with physics language attached, rather than a fit constrained by data, equations, and boundaries.
Operator Learning
  • Partial Differential Equations
  • Deep Learning
  • Surrogate Modeling
 Operator learning makes sense when the job is a fast map between full fields across many related solves. Without fields and surrogates, a reader may mistake it for one more predictor on a table.
Surrogate Modeling
  • Deep Learning
  • Uncertainty And Generalization
 A surrogate is useful only when its repeated query family and tested use range are named. Without uncertainty, speed can be mistaken for scientific trust.
Uncertainty And Generalization
  • Deep Learning
  • Scientific Machine Learning
 Uncertainty and generalization ask whether fitted behavior survives a changed scientific case. Without the scientific job, uncertainty can look like a decorative confidence number.
Neural Differential Equations
  • Partial Differential Equations
  • Deep Learning
  • Optimization For Learning
 The learned part is a rate or missing change rule placed inside a time-evolution calculation. Without differential equations, a reader may miss why small rate errors can accumulate over time.
Symbolic Regression And Model Discovery
  • Optimization For Learning
  • Uncertainty And Generalization
 Symbolic regression searches for a readable rule, then needs changed-case tests to reject neat but wrong formulas. Without changed-case testing, a compact equation can be mistaken for truth.
Graphs And Geometric Learning
  • Deep Learning
  • Scientific Machine Learning
 Geometric learning keeps connections, shapes, and symmetries visible inside learned prediction. Without the scientific object, graph structure can look like a modeling fashion rather than required information.
Attention For Scientific Fields
  • Operator Learning
  • Graphs And Geometric Learning
 Attention is a way to move selected information across large fields or connected objects. Without fields and connections, attention can be misread as proof that all important interactions were captured.
Generative Modeling
  • Deep Learning
  • Uncertainty And Generalization
 Generated scientific samples need checks for validity, rarity, and downstream use. Without validation, plausible samples can be mistaken for physically useful samples.
Foundation Models For PDEs
  • Operator Learning
  • Partial Differential Equations
  • Uncertainty And Generalization
 Broad PDE models depend on field-to-field maps, equation families, and tests on held-out task families. Without these dependencies, scale can be mistaken for coverage of a new scientific case.

How To Use This

If a concept feels vague, move to its Learn First column and read those pages before returning. Most confusion comes from skipping the object being predicted, the rule being checked, or the failure test.
