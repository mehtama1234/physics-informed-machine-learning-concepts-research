Partial Differential Equations

A PDE is a rule for how a whole field changes across space and time.

Domain Story

Weather, temperature, pressure, and fluid velocity are fields. A value at one location matters partly because of the values around it.

Problem

something changes everywhere at once—how do you describe that with math?

Start With What Is Observed

a field such as temperature, pressure, concentration, velocity, or displacement

Name What Is Hidden

how every point in the field affects nearby points over time

Build The Mathematical Shape

1. Name the field, such as temperature or velocity.
2. Name the rates of change across space and time.
3. Add sources, forces, material parameters, and boundaries.
4. Use the rule to connect local change to nearby values.
5. Check conservation, stability, and boundary behavior.

Why This Shape And Not Another

The formula shape is justified only when each part carries a burden from the scientific problem. If a part carries no burden, it is decoration. If a burden is missing, the formula is answering a weaker question.

Observed BurdenThe shape must use a field such as temperature, pressure, concentration, velocity, or displacement, because that is the evidence actually available.
Hidden BurdenThe shape must point toward how every point in the field affects nearby points over time, because that is the answer the scientist still needs.
Use BurdenThe shape matters only if it supports this job: Most physics-informed machine learning borrows its scientific burden from PDEs.
Rejection BurdenThe shape is too weak if it cannot be tested this way: change the boundary, grid, source term, or physical scale and check conservation, stability, and measured error

Hand Derivation

Start with a quantity spread across space, such as temperature, pressure, concentration, velocity, or displacement. One value cannot describe it because each location is tied to nearby locations, sources, and boundaries.

Term Why It Enters Check
field value The object being described is a value at many places, not one number for the whole system. If the field is reduced to independent points, movement, flow, stress, or diffusion can be lost.
change rates The equation must say how the field changes in time or across space, because that is where the physical rule lives. If the rates are wrong, the equation can look neat while giving the wrong evolution.
sources and boundaries A field can obey the same local rule but behave differently when heat, force, material, or edge conditions change. If sources or boundaries are vague, the equation may describe a different physical problem.

Final Line: A PDE is a compact way to say how a field, its local changes, its sources, and its boundaries must agree.

Plain Formula

change over time = transport through space + diffusion (smoothing) + sources, with boundary and initial values acting as constraints (not extra added terms)

Smallest Useful Formula

The smallest useful formula must start from a field such as temperature, pressure, concentration, velocity, or displacement, carry the answer toward how every point in the field affects nearby points over time, and include a check that can fail: change the boundary, grid, source term, or physical scale and check conservation, stability, and measured error.

First Wrong Simplification

The first wrong shortcut is to keep the part that gives an answer while dropping the part that checks it. That would hide this failure: change the boundary, grid, source term, or physical scale and check conservation, stability, and measured error.

Failure Test

Red Flags

  • The boundary condition is vague.
  • The learned answer ignores conservation.
  • The grid or resolution changes the conclusion.
  • Small visual error hides a large error in the quantity people care about.
