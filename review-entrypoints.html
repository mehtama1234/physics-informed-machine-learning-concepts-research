Review Entrypoints

This page gives a reviewer a concrete route through the package. It separates four jobs: see the whole argument, inspect the core concepts, use the package for a scientific situation, and check whether source support is clear.

End-To-End Test

A strong review can follow one concept from transcript evidence, to topic page, to diagram, to decision guide, to a domain example, then back to the coverage matrix. If that route breaks, the missing link is the next editorial task.
