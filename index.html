Central Big Picture

The course family asks how machine learning can help science without throwing away physics. The recurring problem is not simply prediction. The real problem is turning data, equations, simulations, geometry, and uncertainty into models that can be trusted for a named scientific job.

Core Route Through The Material

  1. Start with scientific data and the need to predict or explain a changed case.
  2. Add neural networks as adjustable function builders, but keep their limits visible.
  3. Bring in PDEs, physics penalties, operators, geometry, and uncertainty as ways to stop the model from becoming an unchecked fit.
  4. Judge every method by the scientific claim it can support and the failure case it can expose.
