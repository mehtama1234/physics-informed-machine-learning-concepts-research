Uncertainty Reader Check

Setup

A model works on familiar examples and is now proposed for a new scientific setting.

Questions

  1. How is the new setting different from training?
  2. Which difference matters scientifically?
  3. What error should be measured?
  4. What use range can be stated?
  5. What first failure would stop use?

Strong Answer Should Say

The answer names the actual shift, such as geometry, parameter range, sensor, scale, boundary, or regime. It measures the error that matters for the scientific decision, states the use range, and names a condition that would stop use.

Weak Answer Warning

A weak answer reports one score without saying what changed.

Acceptance Sentence

A reader passes only if they can say, in ordinary language, The answer names the actual shift, such as geometry, parameter range, sensor, scale, boundary, or regime. It measures the error that matters for the scientific decision, states the use range, and names a condition that would stop use.

First-Principles Scoring Rubric

CriterionPassFail
Observed evidence Names what is actually known before the method is chosen. Starts with the method name.
Hidden quantity Names the field, rule, answer, or use range still missing. Treats the prediction as if it were already known.
Mathematical move Explains what the math carries from evidence to missing quantity. Uses a label without saying what job the math does.
Changed-case rejection Names a changed case that could make the claim fail. Reports a score without a failure condition.
