Surrogate Reader Check

Setup

A trusted simulation is too slow for a design loop.

Questions

  1. What trusted source does the surrogate replace?
  2. Which inputs will be varied?
  3. What output quantity matters for decisions?
  4. Where was the fast stand-in checked?
  5. When should the full solver be used again?

Strong Answer Should Say

The surrogate replaces a named solver or experiment only inside a named query family. Inputs and outputs must match the decision. The stand-in should be checked near the edge of intended use, and the full solver should return when the query leaves that range or when errors affect the decision quantity.

Weak Answer Warning

A weak answer treats speed as trust.
