Candidate Generation Flow

Purpose

Show how a model makes possible candidates that still need scientific checks.

Flow

1. known conditions
2. source of variation
3. generated candidate
4. measurement and rule checks
5. accepted or rejected candidate

Watch for: A candidate that looks familiar can still break the equation, boundary, measurement, or intended use family.

How To Read It

Move left to right. Each box names the information being carried forward. The last box is not decoration; it is the check that decides whether the claim should be trusted.
