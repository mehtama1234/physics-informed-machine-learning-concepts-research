First-Principles Walkthrough

What this lecture is really about: What neural networks actually are and how we teach them to work

The question it answers: How do we build machines that can learn patterns from examples? What is a neural network, why does it work, and how do we train it?

Something concrete to hold onto: Imagine you have a pile of noisy measurements (say, points scattered around a curve on a graph with some error). You want to find a smooth function that fits through those points. A neural network is just a very flexible function that we can bend and twist to match your data.

Let's start with the simplest idea. If you have input measurements and you want to predict an output, you are doing function fitting. Think of polynomial regression: given a set of (x, y) points, you assume the true relationship is some polynomial curve, and you find the coefficients (weights) that minimize the squared distance between your predictions and the actual data. This is the basic approach. Neural networks do the exact same thing—they take an input, pass it through a mathematical function (whose shape is controlled by parameters we call weights and biases), and produce an output. The training goal is identical: adjust those weights so the output matches the training data as closely as possible.

The key question is: what does that mathematical function look like? For polynomial regression, we know it's a sum of powers of x. For a neural network, we build something more intricate by stacking layers together. Each layer does a simple operation: multiply the previous layer's output by a weight matrix, add a bias vector, then pass the result through an activation function (a nonlinear curve like ReLU or tanh). If we removed the activation functions and just multiplied matrix by matrix, we'd collapse back to a single linear function—useless. The activation functions are what give neural networks their power: they introduce nonlinearity, allowing the network to bend and twist to fit complicated data.

A multi-layer perceptron (MLP) is the simplest architecture. Imagine a chain of neurons. Each neuron in one layer is connected to every neuron in the next layer (hence 'fully connected'). The first layer takes your input. Each subsequent layer processes the output of the previous layer through the same simple recipe: multiply by weights, add bias, apply activation. By composing these layers, you create a deeper function—a composition of many simpler functions stacked on top of each other. The magic of depth is that the first layers can learn simple features (like edges in an image), middle layers learn more intricate features (like parts), and deeper layers learn the high-level concepts (like faces). This compositional structure is called an inductive bias: we are building in the assumption that the true function is a composition of simpler functions.

Why are neural networks so useful? Because of the universal approximation theorem. This says: with enough parameters (weights and biases), a neural network can approximate any continuous function to arbitrary accuracy. Unlike polynomial regression (which is limited to polynomial shapes) or linear regression (which is limited to lines), a neural network is flexible enough to learn almost any mapping from input to output. This is why they work for image classification, time series prediction, and even learning physics equations.

Now, how do we actually find those weights? For polynomial regression, there is an analytical formula using linear algebra. For neural networks, there is no formula, so we use gradient descent. We compute how much the loss (the squared error between prediction and ground truth) changes when we slightly adjust each weight. The direction of steepest descent tells us which way to tweak the weights to reduce the loss. We take many small steps in that direction, and gradually the network learns to fit the data. This is where backpropagation comes in: it is just an efficient algorithm for computing these gradients using the chain rule. You do a forward pass (compute the output), store the intermediate layer outputs, then do a backward pass where you propagate the gradient signal from the loss back through all the layers to compute the gradient with respect to every weight.

Different problems call for different network architectures. For images, a convolutional neural network (CNN) is much smarter than a fully-connected network. Instead of every neuron connecting to every input pixel (which would require millions of weights), each neuron in a CNN looks at only a small patch of the image. All neurons apply the same filter (share weights), so a 3×3 filter applied to an image only needs 9 weights, not millions. This dramatically reduces the number of parameters, making the network more efficient and less prone to overfitting. CNNs also have translational equivariance: if you slide a dog's head to a different part of the image, the CNN learns the same features.

The real power of deep learning comes from depth. A shallow network might need exponentially more neurons to match the performance of a deep network. Research showed that for image classification, the depth (number of layers) matters much more than width (number of neurons per layer). Early layers detect simple edges and corners; middle layers find nose-like and ear-like shapes; deep layers recognize entire faces. This hierarchical feature learning emerges naturally from training the network end-to-end. We encode this compositional structure as an inductive bias in the architecture itself, and it works.

Finally, there are different ways to use neural networks depending on your problem. Supervised learning: you have input-output pairs and you want to predict outputs from inputs (regression if outputs are continuous, classification if they are discrete categories). Unsupervised learning: you only have inputs, and you want the network to discover patterns or compress the data (autoencoders) or generate new samples that look like the training data (generative models). Autoregressive models: you have sequences and you want to predict the next value given the history (how language models like ChatGPT work). In all cases, the core idea remains: the neural network is a flexible function, and we are fitting it to data by adjusting its weights to minimize a loss.

Key ideas in plain words

  • A neural network is a flexible mathematical function (like a curve) that we fit to data by adjusting its weights and biases to minimize prediction error.
  • Activation functions (like ReLU or tanh) introduce nonlinearity, allowing networks to bend and fit complicated patterns instead of collapsing into straight lines.
  • Universal approximation: with enough layers and neurons, a neural network can learn to approximate any continuous function, which is why they are so general-purpose.
  • Backpropagation is an efficient algorithm that uses the chain rule to compute how much each weight contributed to the overall error, enabling gradient descent training.
  • Architecture matters: convolutional networks for images reduce parameters by having neurons look at only small patches and share weights; depth matters more than width.
  • Different tasks (supervised, unsupervised, autoregressive) all use the same underlying principle: fit a flexible function to data using loss functions and gradient-based optimization.

Worked intuition: Imagine training a network to fit a wavy curve. Start with a random flat function. Backpropagation measures: 'your current prediction at point x=2 is too high by 0.5, and if we increase weight w1 by 0.01 it would improve by 0.03.' The algorithm discovers the gradient—the direction of steepest descent. We take a small step in that direction. After many steps, the function curves and bends to match the data. The key insight: we never analytically solve for weights. Instead, we iteratively measure error, compute gradients, and adjust. This is why autod tools like PyTorch are essential—they automate gradient computation so we only define what the forward function does, and the approach computes the backward gradient pass automatically.

Where it breaks down: Neural networks require a lot of training data to work well. With tiny datasets, a simple polynomial fit may work better because neural networks have so many parameters they can overfit (memorize noise instead of learning true patterns). Computational cost scales with network size; training huge models requires effective hardware (GPUs, TPUs) and careful engineering. Neural networks are also notoriously hard to interpret—because the representation is distributed across many neurons, it is difficult to understand which weights are responsible for which predictions. Finally, universal approximation is a theoretical guarantee (given enough parameters), but it does not tell you how many parameters you need or whether gradient descent will actually find the global minimum in practice.

Takeaway: Neural networks are not magical: they are flexible functions that we fit to data using gradient descent and backpropagation, just like polynomial regression, but more effective because they can compose many nonlinear layers. The art of deep learning is choosing the right architecture (fully-connected, convolutional, recurrent, etc.) for your problem and letting backprop do the work of learning the weights.
