First-Principles Walkthrough

What this lecture is really about: Fourier Neural Operators: Solving PDEs by Learning Infinite-Dimensional Maps

The question it answers: How can we teach a machine to solve partial differential equations (physics equations) in a way that works at any resolution, not just the resolution it was trained on? The key insight: work in frequency space instead of physical space.

Something concrete to hold onto: Imagine you trained a neural network to solve weather equations on a 64×64 grid, but then you want to use it on a 128×128 grid (higher resolution). Most approaches fail completely—the error explodes. Why? Because they learned the grid spacing itself, not the underlying continuous physics. Fourier Neural Operators avoid this by thinking in terms of frequencies (like musical notes) rather than grid points.

The fundamental problem: We want to train a machine to act like a solver for physics equations. These equations naturally live in infinite-dimensional spaces (they work for any smooth function), but our computers only handle finite arrays of numbers. The previous approach sampled a function onto a grid, applied a CNN, and got a grid back. The disaster: if you change grid resolution, everything breaks. This happens because convolutions in physical space secretly depend on grid spacing—the kernel keeps its width fixed even though the grid changes, so it sees different neighboring points.

To understand the solution, first grasp representation equivalence. Think of it as a commuting diagram: you can go directly from an input function to an output function in infinite dimensions (this is what physics knows), or you can detour through finite dimensions by encoding (sampling to a grid), doing finite-dimensional work, then reconstructing (interpolating back). For these to give the same answer, you must ensure no aliasing error happens at each layer. Aliasing is what occurs when you sample a musical signal too coarsely and high frequencies disguise themselves as low frequencies. The fix: design your encoding, neural operator, and reconstruction so the diagram commutes perfectly.

The encoding and reconstruction use Fourier-space ideas. For periodic band-limited functions (functions with only finitely many frequency components), sampling at enough grid points is lossless via the Nyquist-Shannon theorem: you can exactly recover a function from its grid values using sinc (pronounced 'sink') basis functions. This is beautiful—it means grid values and the continuous function have a one-to-one correspondence. When you refine the grid, you can move between different grids by: lifting the coarse grid values to the infinite-dimensional space via sinc interpolation, applying the operator, then projecting back down.

CNNs fail this test. A CNN uses a fixed-size kernel that slides across the grid. When the grid changes, the kernel still touches the same number of neighbors, but now they're at different physical locations and have different heights. This breaks the commuting property and introduces errors that grow layer by layer. By contrast, if you work in Fourier space (frequency space), convolution becomes pointwise multiplication—you multiply each frequency component by a learnable number. This is resolution-independent because you're not moving a window; you're scaling frequencies. The trick: compute the Fourier transform via FFT (very fast), do multiplication in frequency space, apply the inverse FFT.

Enter Fourier Neural Operators (FNO), which combines several smart tricks. First, you expand the number of feature channels via a lifting operator—like expanding from 'temperature only' to 'temperature plus 100 learned hidden features.' Then, the core layer does: (1) Fourier transform the input (via fast FFT), (2) pointwise multiply by a learnable Fourier multiplier in frequency space, (3) inverse Fourier transform back to physical space, (4) add a residual connection (keeping some information directly from the input), (5) apply a learned linear feature-mixer (not position-dependent, just mixing channels). Finally, a projection operator brings you back to the physical output (e.g., pressure, velocity). You stack several such layers, each adding nonlinearity (ReLU, etc.) between them.

Computational magic: The original kernel integral operator costs O(n²) per layer—quadratic in the number of grid points—because you integrate over all pairs. In FNO, you only keep K low frequencies (say, 20 instead of 100), and the FFT costs O(n log n), not O(n²). Multiplying a matrix of size (2K+1)² by M features is much cheaper than the full kernel. This is why FNO scales to high-resolution problems where dense kernel operators would die.

A crucial caveat emerges when you add nonlinearity. A band-limited function has frequencies capped at some bandwidth. When you square it (the simplest nonlinearity), you get double the frequencies—this is pure Fourier mathematics. So ReLU and other activations leak energy to high frequencies, breaking the band-limiting assumption. On periodic, truly band-limited problems, FNO works perfectly across resolutions. On problems where activations generate high frequencies that matter, you get aliasing errors that FNO cannot escape. The random-assignment example in the lecture shows this catastrophically: small grid changes cause large errors even for a simple, well-defined operator.

The takeaway: FNO is a principled way to approximate operator learning when (a) you work on periodic domains or can wrap non-periodic ones, (b) your operator's output mostly stays within the frequencies present in the input (true for many smooth PDEs but not all), and (c) you can afford the upfront cost of FFTs. It beats CNNs because it truly learns an operator on function space, not a discrete map. It's not a magical fix—you must respect the physics (band-limiting or frequency decay) and the grid (Nyquist sampling). When those hold, even a model trained on a coarse grid predicts perfectly on a fine grid.

Key ideas in plain words

  • Operator learning means learning a map from infinite-dimensional function spaces to function spaces, not from vectors to vectors. A CNN secretly learns grid-spacing-specific discrete maps, which breaks when resolution changes. Proper operator learning requires representing both the continuous level (what physics does) and discrete level (what computers do) and ensuring no hidden loss (aliasing) happens between them.
  • Fourier transforms switch between physical space (where you see spatial shapes) and frequency space (where you see oscillation rates). Convolving in physical space becomes multiplying component-by-component in frequency space. This is resolution-independent because you're operating on frequencies, not grid positions. Fast Fourier Transform (FFT) makes this O(n log n) instead of O(n²).
  • Band-limited functions have only finitely many Fourier frequencies. The Nyquist-Shannon theorem says: if you sample densely enough, grid values perfectly capture the function, with lossless reconstruction via sinc interpolation. This creates the bijection between grids at different resolutions, provided both grids are dense enough for the same frequencies.
  • FNO layers: Fourier transform → multiply by learnable frequency weights → inverse Fourier transform → add residual → pointwise nonlinearity → feature-mixing (linear operation per point). The lifting operator expands channels before this core, the projection operator shrinks channels after. Stacking layers adds depth.
  • Nonlinearities (ReLU, sigmoid, etc.) fundamentally generate new high frequencies from low-frequency inputs—mathematically, this is how they compress or distort signals. This breaks band-limiting, causing aliasing errors when the resolution changes, even in FNO. This is not a bug in FNO; it's a statement about approximating nonlinear operators.
  • Fast Fourier Transform (FFT) computes Fourier coefficients in O(n log n) time. Truncating to K frequencies instead of n saves computation by a factor of n/K. For an n² grid in 2D with n=100, keeping 20 frequencies is 25× faster than all frequencies. This is why FNO scales.
  • Resolution independence: If you work in a fixed frequency space (say, frequencies -K to +K), it does not matter if your grid has 64 or 128 points—you project both onto the same K frequency components. This is why a model trained on one grid transfers perfectly to another, as long as both grids satisfy the Nyquist condition for those frequencies.

Worked intuition: Take a simple 1D Fourier Neural Operator on a periodic function. Suppose your input is the values u = [u₁, u₂, ..., u_n] at n grid points. Step 1: Lift to features: P(u) expands u to a matrix of m > 1 channels. Step 2: Fourier layer. (a) FFT each channel: û = FFT(u_lifted), giving you frequency coefficients. (b) Keep only 2K+1 frequencies (e.g., K=10, so 21 frequencies). (c) Multiply by a learnable weight matrix R (having real and imaginary parts): v̂ = R · û. (d) Inverse FFT: v = IFFT(v̂) back in physical space. (e) Add residual: add part of u_lifted directly. (f) Apply ReLU pointwise. Step 3: Repeat for several layers. Step 4: Project Q shrinks features back to your output dimension (e.g., 1 for scalar). The key: if you train this on a 64-point grid with frequencies [−10, ..., 10], the model learned relationships between those frequency components. When you apply it to a 128-point grid, you FFT the input (now with 128 points), extract the same frequencies [−10, ..., 10], multiply by R (unchanged), and IFFT. The model sees exactly the same frequencies it trained on, so generalization is automatic. By contrast, a CNN with a fixed 3×3 kernel on 64 points sees neighbors 1 grid-unit apart; on 128 points, those neighbors are only 0.5 grid-units apart, so the kernel is effectively twice as wide, changing the learned map entirely.

Where it breaks down: FNO inherits one fundamental limit from any attempt to learn nonlinear operators: nonlinearities (ReLU, sigmoid, polynomials, etc.) generate new frequencies. A band-limited function stays band-limited under linear operations (convolution in frequency space is just multiplication) but not under nonlinearity. For example, sin(x) has only frequency 1, but sin²(x) has frequencies 0 and 2. In FNO, this happens after each activation. If the problem naturally damps high frequencies (like smooth PDEs), the leak is small. But if high frequencies are important (random permutations, shocks, step functions), activations introduce uncontrolled aliasing. Additionally, FNO assumes periodic boundary conditions or at least that you can wrap the domain; handling open boundaries (e.g., on a semi-infinite line) is awkward. Finally, the method assumes the continuous operator is well-defined and Fourier methods are sensible; for operators with singularities or discontinuities, results degrade.

Takeaway: Fourier Neural Operators solve operator learning by working in frequency space instead of physical space, which makes them automatically resolution-independent for smooth, band-limited problems. The core insight is that convolution becomes multiplication in frequency space, and multiplication is agnostic to grid resolution. Train a model to multiply frequency components, apply it to any grid, and it works. The catch: nonlinearities leak frequency energy, so FNO is faithful only when the underlying operator mostly preserves frequencies (true for many physics PDEs, false for random permutations). This is a feature, not a flaw—it tells you when the approach will work in practice.
