Broad PDE Coverage

Situation

One model is proposed for many equations, grids, parameters, or scientific tasks.

Best Starting Point

Foundation models for PDEs

Why This Fits

The claim is about shared structure across tasks, so whole task families must be tested.

Decision Burden From First Principles

A method choice is justified only when the shortage, evidence, hidden need, mathematical move, and rejection test line up. This table states what the choice has to carry before the starting point is defensible.

Shortageone trained model may be asked to handle many related equations, grids, parameters, or physical settings
Observed Evidencemany PDE problem instances across equations, grids, parameters, or physical settings
Hidden Needwhich shared structure carries from one scientific task to another
Why This Starting Point Earns Its Placetrain one broad model to reuse structure across many related field-prediction tasks
What The Choice Carriesbreadth is useful only if the new task shares the structure the model actually learned
First Rejection Testhold out a new equation family, boundary type, scale, or rare regime and compare against a trusted solver

Choice Must Fail If

Reject this starting point if the situation cannot provide the observed evidence, if the hidden need is not the quantity the decision uses, or if the first rejection test cannot be run.

Use If

  • many task families exist
  • shared structure is plausible
  • whole families can be held out

Avoid If

  • the new task is only assumed to be covered
  • rare regimes are missing
  • scale is treated as proof of scientific trust

Evidence Needed

held-out task-family tests, trusted-solver comparisons, boundary and scale tests, and failure reports
