Expensive Repeated Decisions

Situation

A trusted solver or experiment is too slow for design, search, control, or uncertainty sweeps.

Best Starting Point

Surrogate modeling

Why This Fits

A fast stand-in can answer repeated questions if its use range is stated and checked.

Use If

  • the slow trusted source is named
  • the repeated query family is narrow enough to test
  • the decision quantity is explicit

Avoid If

  • speed is the only evidence
  • the query family keeps changing
  • edge cases are not compared against the trusted source

Evidence Needed

full-solver comparisons near the edge of use, decision-metric error, and a stated use range
