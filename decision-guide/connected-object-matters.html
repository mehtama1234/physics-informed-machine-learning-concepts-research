Connected Object Matters

Situation

The object is a molecule, mesh, graph, surface, or network where connections carry part of the scientific meaning.

Best Starting Point

Graphs and geometric learning

Why This Fits

Flattening the object can hide which parts influence which other parts.

Use If

  • nodes, edges, distances, or geometry matter
  • symmetries or mesh changes can be tested
  • the target property depends on interactions

Avoid If

  • the chosen graph is arbitrary
  • long-range effects are missing
  • rotation or mesh changes break the claim

Evidence Needed

mesh-change tests, symmetry checks, missing-interaction tests, and target-property error on changed objects
