Question To Topic Guide

Start With The Need

Use this page before choosing a method name. Say the ordinary scientific need first: what you can see, what you need next, and what would make the answer fail. Then open the first topic that carries that need.

The point is not to memorize labels. The point is to learn the route from a real shortage to a claim you can test. If the route cannot name the evidence, the missing quantity, and the first changed case, the explanation is not ready.

Everyday QuestionOpen This TopicWhy This Is The First StopWhat To Check Before Trusting It
I have many examples, but I do not have a short rule. Where do I start? Deep Learning scientists have many measured examples but no formula that predicts the next case. The first move is to adjust many weights until the model maps familiar inputs to the right outputs. trained model passes on familiar data but crashes on new material, boundary condition, or scale it never saw before
I have a few measurements and a known equation. How do I make them work together? Physics-Informed Neural Networks sparse measurements from experiments, but the answer must obey known physical laws like gravity or heat flow. The first move is to fit a neural network while also measuring how badly its output violates the known equation. the penalty term hides small errors near boundaries, in thin layers, or where the real solution changes suddenly
My quantity changes across space and time. What language describes that change? Partial Differential Equations a quantity changes over space and time, so one number is not enough to describe what's happening. The first move is to write a local change rule that uses rates across space and time. when data or learning skips the actual PDE constraints, it can ignore boundary conditions or conservation laws that the PDE was always enforcing
I need the whole answer field for new inputs, not only one solved case. What carries that map? Operator Learning engineers need to predict all the fields (temperature, pressure, flow) across a space and time for many input cases, not just one. The first move is to learn the map from problem input to solution, not only one solution at a time. the learned map produces plausible-looking fields that actually violate the physics or break when you shift the geometry
I need data, equations, units, and checks to live in one scientific claim. What is the broad home for that? Scientific Machine Learning predictions must obey the physical laws that define the problem, not just fit the data. The first move is to combine learned prediction with scientific checks that name what the claim is allowed to mean. if no clear equation or boundary condition exists, the network learns the data shape but not the underlying rule
My trusted solver is too slow to run for every design or control question. What is the first shortcut to study? Surrogate Modeling running a full simulation is too expensive to do for every design choice or question. The first move is to train a cheaper stand-in for the expensive input-output behavior. gives plausible-looking answers for inputs it never saw during training, with no warning that they are wrong
I have a prediction, but I need to know when to believe it. What topic handles that? Uncertainty And Generalization a prediction from a model is only useful if you know under which conditions you should actually trust it. The first move is to separate fit on familiar examples from evidence on changed examples. training error looks good while the model silently fails under new geometry, parameter range, sensor, or physical regime
The model is changing its settings. How do I know what it is being asked to improve? Optimization For Learning models need a way to measure progress so they know which settings are better or worse. The first move is to change model settings to lower the written score. the score goes down while the model learns wrong physics, if the score missed the real constraint
I need several possible fields, molecules, shapes, or scenarios, not one answer. Where do I start? Generative Modeling some tasks need many plausible examples, not a single best prediction, to explore what's possible. The first move is to learn how to sample new candidates that resemble the training family. a generated fluid flow looks smooth and realistic but conserves no mass; a design candidate is manufacturable in appearance but physically infeasible
My object has parts, neighbors, bonds, mesh points, or shape. Which topic keeps those relations visible? Graphs And Geometric Learning molecules, proteins, and meshes have a shape and connections that rows of numbers throw away. The first move is to let information move along the object connections instead of flattening the object into a plain row. if the graph misses a real bond or connection, or if parts of the shape rearrange and the model sees a stranger structure
A system changes over time, but the rate rule is partly unknown. What topic should I open? Neural Differential Equations scientists watch a system change over time but don't know the rule driving that change. The first move is to learn the missing rate rule and place it inside a time-evolution calculation. a small error in the learned rate, repeated over hundreds of time steps, pushes predictions into wildly wrong territory
I want a readable equation from measured variables. What topic is about that search? Symbolic Regression And Model Discovery a scientist may need a readable equation, not a numerical model that predicts but cannot be understood. The first move is to search for a readable equation that fits the data and survives a changed case. a neat formula fits your lab's data perfectly but uses the wrong variables or breaks when conditions shift
I want one field model to help across related PDE tasks. What should I read first? Foundation Models For PDEs scientists train separate models for each PDE, each grid size, each parameter—expensive duplication. The first move is to train one broad model to reuse structure across many related field-prediction tasks. the model trains on common cases and misses rare physical regimes, different boundary shapes, or unseen initial conditions
Faraway parts of a field may affect the local answer. What topic explains that information route? Attention For Scientific Fields a local spot in a field may depend on faraway information, but scanning everywhere costs too much. The first move is to let the model choose which parts of the field exchange information. when attention weight patterns are wrong, the model skips over long-range effects that are essential to the physical quantity being predicted

If Your Question Mentions Shape

If the question mentions a mesh, molecule, graph, boundary, surface, hole, neighborhood, or connected part, slow down before flattening the object into a plain row. Ask what relation carries the scientific quantity. Then open the shape guide and the topic row above that names the same relation.

Reader Test

A reader understands the first-principles route when they can start with one everyday question, choose one topic, and say why that topic is the first stop without using the method name as the reason. The answer should name the evidence in hand, the hidden thing needed, the mathematical move, and the changed case that could reject the claim.
