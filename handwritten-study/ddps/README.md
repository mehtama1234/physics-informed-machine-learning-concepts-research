# DDPS Hand-Written Study Notes

This folder is for transcript-grounded notes on the DDPS seminar playlist:

https://www.youtube.com/playlist?list=PLy9rIbGDXrG2Ly0LPYNuNn1ohQTqO6mmp

The rule for this folder is simple: do not auto-fill lesson pages from a template. A lesson note should exist only after the transcript has been read enough to say what the speaker actually discussed.

The notes should connect back to the AISE 2025 course spine:

- real scientific or engineering question
- evidence available
- hidden physical quantity or model decision
- mathematical or computational move
- failure mode
- plain-language lesson for a new reader

The DDPS playlist is broader than the 2025 AISE lectures. It includes PINNs, reduced-order models, numerical methods, differentiable simulation, graph networks, uncertainty, fluids, materials, operators, inverse problems, and scientific discovery. The job here is not to summarize every video with the same shape. The job is to build a map of what each speaker adds to the core question:

How do data, equations, simulation, and learned models work together without hiding the scientific claim?

## Source Folders

- Raw playlist metadata: `../../raw-material/playlists/ddps.json`
- Raw captions and video metadata: `../../raw-material/transcripts/ddps/raw-vtt/`
- Clean transcript text, when converted: `../../raw-material/transcripts/ddps/clean/`
- Hand-written lesson notes: `lessons/`
- Cross-course theme bridges: `theme-bridges/`

## Current Working Standard

Each completed lesson note must make clear:

- which transcript file it used
- what the talk actually discussed
- what the first-principles idea is
- how it connects to the prior AISE course
- what not to overclaim from the transcript

That is a quality bar, not a page template.
