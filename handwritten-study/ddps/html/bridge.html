Theme bridge

DDPS To AISE 2025

The AISE 2025 course is a structured course. The DDPS playlist is a seminar series. That changes how to read it.

AISE gives the spine: start with scientific and engineering questions, learn deep learning as input-to-output fitting, add equations through PINNs, move from one solve to many solves through operator learning, handle grids and irregular geometry, then apply similar representation questions to chemistry and biology.

DDPS should be read as a set of deeper side rooms around that spine. Each DDPS talk usually takes one hard issue and pushes it further: training failure, model reduction, numerical stability, differentiable simulation, inverse problems, uncertainty, scientific discovery, or domain-specific simulation.

Bridge 1: PINNs

AISE teaches that the PINN loss combines data, PDE residual, and boundary or initial information.

DDPS video 1 adds that the combined loss can be hard to train. The failure is not just a coding problem. It can come from the shape of the optimization problem, the balance between loss terms, and the way gradients move during training.

The plain learning path is: understand the PINN idea, read the DDPS failure talk, ask why the loss is hard to train, then decide whether to trust or reject the result.

Bridge 2: Reduced-Order Modeling

AISE teaches that a surrogate model can make repeated scientific solves cheaper.

DDPS video 2 adds that cheaper is not enough. The surrogate has to compress the right thing. If a pulse, front, interface, or shock is moving through the domain, a fixed small set of shapes can fail even when the physics is simple.

The missing burden is to notice motion as motion. The model may need to learn how the feature travels, not merely store many copies of the feature in different positions.

The plain learning path is: understand that a PDE solution is a field over space and time, notice whether the field changes by changing shape or by moving features, ask whether the model represents the motion directly, then judge whether the reduced model is actually useful.
