Do Not Learn The Coordinate Choice

Read This Chapter As One Claim

Start with a simple mistake. You describe the same bridge, molecule, graph, field, or design in two different ways. You change the units, rotate the coordinate frame, relabel the nodes, or choose a different mesh order. The physical thing did not change. If the learned model gives a different physical answer because of that bookkeeping change, it learned the notebook instead of the object. This chapter is about building models that know which changes are only changes in description.

Everyday problem The same object can be written down many ways, and a large neural network may waste data memorizing those arbitrary descriptions.
Shared promise Build known symmetries into the model so coordinates, units, rotations, and graph labels behave the way physics says they should.
Hidden danger If the imposed symmetry is false, the model may be prevented from learning a real effect that actually depends on the changed feature.
First rejection test Rewrite the same case with different units, labels, rotation, or mesh ordering; reject the model if the physical prediction changes in the wrong way.

This chapter uses video 69, Soledad Villar's DDPS talk on the passive symmetries of machine learning. The talk is about a quiet but important source of mistakes: a model may accidentally learn details that come only from how we wrote the data down, not from the physical object itself.

The first-principles question is this: when two data arrays describe the same physical thing, can we make the learning model give consistent answers instead of wasting data learning the representation accident?

same physical object
different representation
prediction should transform consistently
build that into the model

Overparameterized Models Need The Right Bias

Modern neural networks can have far more parameters than training examples. They can fit real labels, wrong labels, shuffled pixels, and noise. So the question is not only whether the model can fit. It is why it should fit in a way that generalizes.

The talk uses the phrase inductive bias for this. In simple words, an inductive bias is the useful assumption we bake into the model so it prefers the right kind of answer. Symmetry is one of the strongest such assumptions.

huge model can fit anything
training data are finite
many fits are possible
symmetry guides the choice

Active Symmetry Is A Pattern In The World

Active symmetries are physical regularities. If the law does not change when time is shifted, energy conservation may appear. If it does not change when space is shifted, momentum conservation may appear. If it does not change under rotation, angular momentum may appear.

These are symmetries of the system itself. They say that when the world is changed in a certain way, something physical remains preserved.

shift time
shift space
rotate system
physical law stays consistent

Passive Symmetry Is A Pattern In The Description

Passive symmetries are different. They come from our choice of description. The same object can be written in different coordinates, different units, a different node order, or a different gauge. The object did not change. Only our bookkeeping changed.

A good model should not care about arbitrary bookkeeping. If we switch kilograms to pounds, the prediction should scale correctly. If we relabel graph nodes, the graph prediction should not change except for the same relabeling in node-level outputs.

choose coordinates
choose units
choose graph node order
object is unchanged

Graphs Show The Idea Cleanly

A graph can be written as an adjacency matrix. But the matrix depends on the order chosen for the nodes. If we reorder the nodes, the rows and columns change, while the graph itself is the same.

For a graph-level output, such as a single property of the graph, the answer should be invariant to node ordering. For a node-level output, the answer should be equivariant: if the nodes are relabeled, the outputs should be relabeled the same way.

same graph
different matrix ordering
graph output unchanged
node output relabels

Message Passing Is Weight Sharing On A Graph

Graph neural networks often implement this symmetry through message passing. Each node sends messages to neighbors using the same message function, and each node aggregates incoming messages in a way that does not depend on arbitrary ordering.

This is why the model respects node relabeling. It asks "who is connected to whom?" instead of "which row number was assigned to this node?"

node sends message
neighbor receives
same function reused
ordering does not matter

Particle Systems Need Rotation-Aware Outputs

For point clouds or particle systems, a scalar such as energy should not change if the whole system is rotated. A vector output such as velocity or force should rotate along with the input.

The talk explains one direct construction. Rotation-invariant scalar features can be built from pairwise inner products. Rotation-equivariant vector outputs can be built as linear combinations of input vectors with coefficients that depend only on those invariant scalar features.

rotate all particles
inner products stay fixed
scalar prediction unchanged
vector prediction rotates

The Double Pendulum Combines Two Symmetries

The talk uses a double pendulum with springs. If gravity is included as an input, rotating the whole coordinate description can be treated consistently. That is a passive rotation symmetry.

The system is also Hamiltonian, meaning there is an energy-like quantity that should be conserved. A Hamiltonian neural ODE can learn that scalar Hamiltonian and then use the Hamiltonian structure to integrate the motion. That adds an active physical symmetry to the passive coordinate symmetry.

include gravity vector
respect rotation coordinates
learn Hamiltonian
conserve structure better

Units Are Also A Symmetry

If a model is physically meaningful, changing kilograms to pounds or meters to centimeters should not create a new law. The numbers change, but the physical prediction changes in a predictable way.

The Buckingham Pi theorem gives a way to build dimensionless features. The model can learn from ratios and combinations with no units, then rescale the output correctly. This is old dimensional analysis reappearing as machine-learning architecture.

change measurement units
physical system unchanged
use dimensionless features
rescale output correctly

Symmetry Reduces The Search Space

The statistical argument is simple at a high level. If the true answer has a symmetry, then forcing the model to obey that symmetry removes many wrong functions from consideration. The learner has less irrelevant freedom.

That can improve sample complexity and generalization. The caveat is important: this helps when the symmetry is actually correct. If we impose a false symmetry, we may block the model from learning the truth.

true answer has symmetry
model class is restricted
fewer wrong fits remain
generalization can improve

Cosmology And Vegetation Use The Same Lesson

The cosmology example uses cheap dark-matter-only simulations to predict properties of more expensive hydrodynamic simulations. The model respects rotation and unit equivalence so it does not learn artifacts of representation.

The vegetation example also involves physical quantities with units: rainfall, water uptake, vegetation loss, and related dynamics. Unit-consistent regression improves the modeling because it respects how the physical quantities must scale.

cheap cosmology simulation
expensive target simulation
vegetation dynamics units
symmetry improves prediction

Learning The Symmetry Is Still Hard

In the Q and A, the natural question is asked: what if we do not know the symmetry ahead of time? The answer is that some work tries to learn symmetries from data, but this is not fully solved.

This matters in scientific machine learning because unknown systems may have hidden structure. But when we do know the symmetry from coordinates, units, graph labels, rotations, or conservation laws, it is usually wasteful to ask the model to rediscover it from data.

unknown symmetry may exist
learning it is hard
known symmetry is free knowledge
build it in when correct

Why This Also Matters For Design

Design and topology optimization are full of representation choices. A shape can be meshed many ways. A graph can be labeled many ways. A part can be described in different coordinate systems or units. A learned design surrogate should not change its answer because the bookkeeping changed.

This chapter gives a design rule: identify what transformations should not change the decision, and what transformations should change the output in a predictable way. Then choose features or architectures that enforce those facts before training.

same design, different description
surrogate should agree
output should transform correctly
optimize real design, not labels

The Chapter In One Chain

First, overparameterized models can fit many wrong functions, so they need useful assumptions. Second, active symmetries are physical regularities such as conservation laws. Third, passive symmetries come from arbitrary representation choices such as coordinates, units, or node order. Fourth, graph learning shows the idea: relabeling nodes should not change a graph-level prediction. Fifth, message passing builds this relabeling symmetry into the architecture. Sixth, particle systems use rotation-invariant scalar features and rotation-equivariant vector outputs. Seventh, the double pendulum example combines coordinate symmetry with Hamiltonian energy structure. Eighth, units are also a symmetry, and dimensional analysis gives dimensionless features. Ninth, correct symmetry constraints reduce the search space and can improve generalization. Tenth, cosmology and vegetation examples show these ideas outside toy problems. Eleventh, learning unknown symmetries is possible but still difficult. Twelfth, design models should not optimize artifacts of labels, units, coordinates, or mesh representation.

The chapter's core idea: a learning model should not waste data learning the arbitrary way we described the object. Build in the symmetries that come from coordinates, units, labels, and known physics.

How To Test Whether You Understood This Chapter

Explain active versus passive Active symmetry is a regularity of the physical system, such as a law staying consistent under time shift or rotation. Passive symmetry is a regularity of the description, such as changing units or relabeling graph nodes while the object stays the same.
Explain the graph example from zero A graph is not the same thing as one chosen adjacency matrix. If you reorder the nodes, the matrix changes but the graph does not. A graph-level prediction should stay the same, and a node-level prediction should relabel with the nodes.
Explain why units matter Changing meters to centimeters should not invent a new physical law. A unit-aware model learns from combinations that carry physical meaning, then rescales the answer in the required way.
Connect this to topology and design A topology design can be meshed, numbered, rotated, or measured in different units. A design surrogate should optimize the real shape and real performance, not the accidental node order, coordinate frame, or unit convention used to store it.
