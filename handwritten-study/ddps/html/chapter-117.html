Narrative chapter

Let The Weak Form Clean The Data

This chapter uses video 120, David Bortz's DDPS talk on why the weak form is stronger than it first appears. The talk is about learning equations or parameters from measured dynamics without repeatedly solving the forward model. The central problem is brutal but ordinary: data is noisy, the system may be chaotic, derivatives may be high order, and direct differentiation of measurements can destroy the estimate.

The main idea is to reverse the usual solver story. Finite elements use weak forms to solve equations. Here, the weak form is used to learn equations from data. Instead of guessing parameters, solving the differential equation, comparing to data, and repeating, the method plugs the data into an integrated version of the equation and solves a linear algebra problem for the unknown terms.

Read This Chapter As One Claim

Suppose you filmed a physical system and want to learn the rule behind it. The obvious idea is to measure position, velocity, curvature, and other derivatives at every point. That is exactly where noisy data hurts you. Tiny measurement errors can become huge derivative errors. This chapter says to ask a softer question. Instead of demanding the exact derivative at one point, average the equation over a small clean window, move derivatives onto a smooth test shape that you control, and use many such averaged balances to discover which physical terms the data supports.

The Old Way Solves Too Much

A common parameter-fitting workflow is expensive. Guess parameters. Run the ODE or PDE solver. Compare the simulated trajectory to measured data. Adjust the guess. Run again. This is often called output-error fitting because the comparison is made between model output and data output.

For simple systems this can work. For chaotic or stiff PDEs it can become painful. If the system is spatio-temporally chaotic, a tiny mismatch at the beginning can become a huge mismatch later. Then the optimizer may punish a parameter for a phase shift rather than for the wrong equation. The Kuramoto-Sivashinsky example in the talk makes this vivid: the data is chaotic, the equation has fourth derivatives and nonlinear terms, and forward-solve fitting can spread across seconds to hundreds of seconds with wildly different accuracy.

guess parameters
solve full model
compare trajectory
chaos magnifies mismatch

Equation Error Skips The Forward Solve

The alternative is equation error. Suppose the equation is built from candidate terms: maybe u, u squared, a spatial derivative, a fourth derivative, or an interaction term. If the right equation is a sparse combination of these candidates, then the unknowns are the coefficients multiplying them.

This is the idea behind SINDy: build a library of possible terms, plug the data into that library, and use sparse regression to keep only the terms that matter. For the diffusion equation, for example, the library might contain many candidates, but only the second-derivative term should survive. The output is not only a black-box predictor. It is a readable equation.

choose candidate terms

readable equation emerges

The Derivative Problem Is The Trap

Equation-error methods have a serious weakness. They often need derivatives of the measured data. If the data is noisy, finite differences can amplify the noise badly. A small time step sits in the denominator. That can make the derivative estimate explode even when the original data looks only mildly noisy.

Smoothing before differentiating does not fully remove the danger. The result can depend on the smoothing basis and can introduce bias. Shocks create another problem: the solution may not be classically smooth, so the derivative may not behave like the clean classroom formula. This is why the weak form enters.

data has noise
finite difference divides by small step
noise becomes derivative error
wrong equation can be selected

The Weak Form Moves The Derivative Off The Data

The weak-form move is integration by parts. Instead of differentiating the noisy data directly, multiply the equation by a smooth test function and integrate. Then move the derivative from the data onto the test function. The test function is chosen by us, so it can be smooth, compactly supported, and zero at the boundary of its small window.

In everyday words, the method asks the data a softened question. It does not ask, "what is your exact derivative at this noisy point?" It asks, "over this small window, when I average you against this clean shape, what equation balance do you satisfy?" That averaging reduces noise, and moving derivatives onto the test function avoids differentiating the raw measurement.

multiply by test function
integrate over a window
move derivative onto test function
data is averaged, not differentiated

The Test Function Is A Smudging Magnifying Glass

The speaker describes test functions as compact shapes that are shifted through the domain. Each placement creates one equation. Moving the test function across space and time creates many equations. Together they form a matrix problem: G times the unknown coefficient vector equals b.

The test function does two jobs at once. It smooths the data through integration, and after integration by parts it acts like a derivative smoother. The method is still local enough to detect dynamics in different regions, but it is not pointwise enough to be destroyed by every noisy sample.

There Is A Balance Between Noise And Numerics

The method is not magic. The test function size and shape matter. If the window is too small, numerical discretization error can dominate. If it is too large, the method may smooth away useful information or become limited by noise in another way. The talk breaks the residual into parts: noise error, parameter error, and numerical integration error.

This gives a practical tuning principle. Choose test functions where the numerical error is controlled and the noise has been sufficiently averaged. The speaker shows that Fourier information from the data can help pick a wave-number cutoff and translate that into a useful test-function scale. For the Kuramoto-Sivashinsky fourth derivative, the weak derivative of noisy data can closely track the true weak derivative after the right choice.

small window: numerical error
large noise: noise floor
choose transition scale
weak derivative stays reliable

Scaling The Variables Can Decide Whether Linear Algebra Works

The talk gives a concrete KdV example where the time scale, space scale, and solution magnitude differ by many orders. If the regression matrix is formed without rescaling, its condition number can become enormous. Then the linear algebra may be numerically meaningless even if the mathematical idea is sound.

After rescaling the variables so the numbers live on comparable ranges, the condition number drops dramatically. This is an important practical lesson. Weak-form learning is fast because it becomes linear algebra, but linear algebra still has rules. Units, scales, matrix conditioning, library normalization, and floating-point arithmetic decide whether the answer can be trusted.

The Examples Show Why This Is Useful

The talk reports strong examples across ODEs and PDEs. Lorenz dynamics with ten percent noise can recover parameters with less than one percent error in fractions of a second. Burgers equations with shocks can still recover the correct sparse term under extreme noise levels. Kuramoto-Sivashinsky chaos can recover the important terms and parameters where forward-solve approaches struggle. Other examples include KdV, nonlinear Schrodinger, Navier-Stokes, porous media, sine-Gordon, and reaction-diffusion systems.

The reason these examples matter is not just speed. They show a different route for model discovery. Instead of proposing many candidate PDEs and solving them one by one, weak-form SINDy can test a large library of possible terms through regression. That makes model selection cheaper, more robust to noise, and easier to connect to uncertainty estimates.

Cell Migration Turns Trajectories Into Rules

One application is cell migration. The experimental setting is a sheet of skin cells where part is cut away and the cells move into the wound. Instead of only fitting a continuum PDE, the group studies interacting particle rules: attraction and repulsion, alignment, and drag. Each cell trajectory can be used to infer the rules that guided that cell.

In synthetic mixtures inspired by data, the method can recover different cell types from unlabeled trajectories. A cell that follows nearby cells, avoids crowding, or aligns with cells in front of it leaves a behavioral signature in its trajectory. The learned potentials then become a bridge to biology: instead of only saying "the cells moved this way," the model suggests what kind of sensing or biochemical mechanism might explain the motion.

unlabeled cell tracks

Reduced Models Can Learn Their Own Latent Dynamics

The talk also connects the weak form to reduced-order modeling. One example keeps Hamiltonian structure while reducing a higher-dimensional oscillator. Another uses latent-space dynamics identification: compress high-dimensional PDE data through an autoencoder or POD-like map, learn the reduced dynamics, then expand back to the full field.

The important point is that weak-form SINDy can make the learned latent dynamics robust to noise. In the examples, even with fifty percent noise in the original data, the reduced model can retain useful prediction accuracy and large speedups. This connects directly to earlier chapters on ROMs: compression alone is not enough; the dynamics inside the compressed coordinates must also be learned cleanly.

The Theory Says When Recovery Becomes Reliable

The speaker highlights consistency results. For a large class of models with linear and bilinear terms, and with the highest power in an individual variable no more than quadratic, the method can recover the correct model asymptotically as enough continuum data is added. Many equations in mathematical physics fall into this class.

The probability plots show the idea. With high noise and very coarse data, recovery can fail. As more data and resolution are added, the probability of recovering the correct terms approaches one. Less noise makes recovery easier. The useful lesson is that model discovery is not only a heuristic search; under the right assumptions, there are statements about when the right sparse equation should be recovered.

Hidden Variables Are The Next Hard Problem

A major limitation is that the method needs data for the variables appearing in the equation error. In an epidemic model, we may observe hospitalizations but not every susceptible or asymptomatic person. In pharmacology, we may measure blood concentration but not drug concentration inside every organ. In many physical systems, the measured variable is only a shadow of the full state.

The talk describes a route using differential algebra to reduce the model to equations involving observed variables. That can make weak-form inference possible even when some states are hidden. This is still work in progress, but it matters because real science rarely gives all variables cleanly.

How This Connects To Topology And Design

Topology and design problems often ask for equations or parameters from messy data: material behavior from experiments, closure terms from fine simulations, effective transport from microstructure, continuum laws from atomistic data, or reduced dynamics from high-fidelity fields. Directly differentiating that data can be a bad idea, especially when the data contains noise, shocks, discontinuities, stiff scales, or nonlocal interactions.

The weak-form lesson is useful here. If the candidate law can be written as a library of terms, test those terms through averaged equation balances rather than through raw pointwise derivatives. For topology, that could mean discovering effective stiffness, diffusion, perfusion, reaction, or flow terms from simulations across many designs. It could also help decide which terms belong in a surrogate before optimizing geometry around it.

The Q&A adds a practical warning for nonlocal physics and atomistic-to-continuum learning. Nonlocal terms can be included if the library allows them, but the data must actually contain enough information to identify them. If the trajectories or simulations do not excite a nonlocal interaction, regression cannot invent reliable evidence for it. Diversity of training data is therefore not optional; it is part of identifiability.

Where The Method Should Not Be Overclaimed

The weak form does not remove modeling judgment. The library still matters. If the correct term is missing, the sparse regression cannot select it. If the library is absurdly large or contains huge powers like u to the tenth without physical reason, numerical rank and scale problems can appear. If variables are hidden, more work is needed before the equation-error system is valid.

The method also needs care with test functions, window sizes, noise levels, data resolution, variable scaling, and identifiability. It is fast because it becomes regression, but that also means it inherits the duties of regression: check conditioning, uncertainty, errors-in-variables behavior, and whether the data supports the terms being estimated.

The Chapter In One Chain

First, direct output-error fitting repeatedly solves the model and can fail or become expensive for chaotic, noisy, or stiff dynamics. Second, equation-error methods plug data into candidate equation terms and solve for the coefficients directly. Third, the trap is that those methods often require derivatives of noisy data, and finite differences amplify noise. Fourth, the weak form fixes this by multiplying by smooth test functions, integrating, and moving derivatives from the data onto the test functions. Fifth, sliding many test functions through the data creates a linear regression system. Sixth, test-function scale must balance numerical integration error against noise error. Seventh, variable rescaling is necessary so the regression matrix is not ruined by conditioning. Eighth, this gives robust, accurate, fast recovery on examples such as Lorenz, Burgers, Kuramoto-Sivashinsky, KdV, nonlinear Schrodinger, Navier-Stokes, porous media, sine-Gordon, and reaction-diffusion systems. Ninth, the same idea can infer cell interaction rules from unlabeled trajectories. Tenth, weak-form discovery can learn latent reduced dynamics after compression. Eleventh, consistency theory says correct model recovery becomes reliable for broad linear and bilinear physics libraries as enough data is added. Twelfth, hidden variables require extra reduction before inference. Thirteenth, for topology, materials, atomistic-to-continuum modeling, and design, the practical lesson is to learn readable effective equations from averaged balances instead of trusting noisy pointwise derivatives.

The chapter's core idea: if noisy data makes derivatives unreliable, stop asking the data for pointwise derivatives. Ask the equation in averaged form, move derivatives onto functions you control, and let linear algebra identify the physical terms the data actually supports.
