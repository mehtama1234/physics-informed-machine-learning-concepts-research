Narrative chapter

Let The Experiment Teach The Equation

Read This Chapter As One Claim

Start with a microscope video that is too large for a person to label frame by frame. The goal is not only to track where voids or grains are. The goal is to learn the rule that makes them move, grow, shrink, or change shape. This chapter connects vision, physics, and learning: first turn pixels into physical variables, then use a model that can predict the future, then simplify the learning problem by paying attention where the material actually changes.

Everyday problem Experiments produce huge image streams, but scientists need the hidden law of motion, not just a labeled movie.
Shared promise Use a recognition network to read the experiment and a physics-shaped model to learn a forward equation from those recognized states.
Hidden danger A black-box predictor can match current frames while producing futures that the material process would never allow.
First rejection test Roll the learned law forward, change controlled variables, and inspect systematic errors; reject it if it only tracks images without explaining the motion.

This chapter uses video 80, Yexiang Xue's DDPS talk on scaling up AI-driven scientific discovery by embedding physics modeling into end-to-end learning and using projection. The concrete setting is materials under extreme conditions: high temperature, irradiation, and tiny voids moving inside microscope videos.

The first-principles question is this: if an experiment gives us a huge video, can we learn the physical equation behind the motion without asking a person to label every frame by hand?

The answer in the talk is not "use a bigger neural network." The answer is to connect three things that usually live apart: computer vision to read the experiment, a physics model to predict the future, and a learning loop that adjusts both until the video, the recognized state, and the simulated future agree.

microscope video
recognize physical variables
simulate with a physics model
learn the equation

The Raw Data Is Too Large For Hand Work

The lecture begins with in-situ experiment videos from an electron microscope. A material sample is heated and bombarded by ions. Under the microscope, small void clusters inside the material change size, move, and sometimes change shape.

The practical problem is severe. A short microscope video can contain terabytes of data. The speaker says that manually annotating a ten-minute video frame by frame could take months of full-time PhD work. That is the first reason AI is useful here: not because it is fashionable, but because the raw observation stream is too large for ordinary hand analysis.

heated irradiated material
voids move in video
terabytes of frames
hand annotation is too slow

The Goal Is Not Only Tracking

A simple computer-vision tracker can mark where the voids are. That is useful, but it is not the whole scientific goal. The scientist wants to know why the voids move, grow, shrink, merge, or change shape.

This is why the talk uses partial differential equations instead of only treating each void as a point object. A point model could track a center and a radius. But the void boundary itself can change unevenly, and the shape may not stay circular. A field model can describe the material state around the void and how the interface moves.

track object positions
measure sizes
explain boundary motion
discover physical law

The Recognition Network Reads The Experiment

The first neural network in the framework is a recognition network. Its job is to look at microscope frames and extract the state variables that the physics model needs. In plain language, it turns pixels into physical quantities.

This is different from most PDE-learning settings where the clean state trajectory is already given. Here the state has to be inferred from noisy visual data. The model has to learn what the experiment is showing before it can learn how the physics evolves.

noisy image frame
computer vision network
PDE variable values
state ready for physics

The Physics Network Predicts The Future

The second neural network is a neural differential equation model. Its job is to take the current physical state and predict the later state. It is not a free-form image predictor. It carries the shape of a physics model, with parameters that can be learned from data.

The training loop compares three things: the later annotation, the later recognized state, and the later simulated state. If they disagree, the loss pushes both networks to improve. The recognition network must read the video better, and the physics network must evolve the state better.

recognized current state
physics model predicts
later video evidence
agreement trains both parts

Black-Box Prediction Fails The Future Test

The talk compares the physics-embedded approach with black-box neural prediction. Both can do well on tracking. But when asked to predict the future, the black-box model quickly produces non-physical results. It can make a picture-like answer that does not obey the material process.

This is the central first-principles lesson. Matching observed frames is weaker than learning a rule that can be run forward. A model can recognize what it sees and still fail to understand what can happen next.

tracks current image
rolls forward freely
non-physical future
needs embedded physics

The Interface Is Where The Action Is

The second part of the talk asks how to make this learning scale. The key observation comes from the material examples. In void evolution and grain growth, most of the interesting change happens near interfaces: the edge of a void, the boundary between grains, the moving front where the material state changes.

That means a giant grid may contain many places where almost nothing changes. If the loss function sums errors over the whole grid, it spends effort on many zero or near-zero terms. The physics is not equally active everywhere.

large spatial grid
quiet interior regions
active interfaces
sparse change pattern

Random Projection Compresses The Learning Problem

The random projection idea is to combine many loss terms into a smaller compressed set before learning. At first this sounds dangerous because it changes the loss. But if most terms are zero, random grouping often does not mix many nonzero terms together. The compressed loss can still point toward a good solution while being much cheaper to compute.

The talk reports that for sparse and decomposable PDE systems, the method can learn reasonable dynamics even after projecting the data down to a tiny fraction of the original size. The practical message is: use the structure of the physical problem before spending compute everywhere.

many grid loss terms
most are zero
randomly group terms
learn in compressed space

Sparsity Is A Physical Fact, Not A Styling Choice

The talk is careful that projection works here because the PDE updates and feature terms are sparse. That is not true for every system. If change is spread everywhere, random projection can hide important differences. If the physics is interface-driven, compression has a reason to work.

This is an important habit for the whole course. A scaling trick is not automatically valid. It is valid when the physical system gives it a reason. Here the reason is that the material's visible evolution is concentrated near boundaries.

check the physics
find sparse updates
compress with reason
avoid blind scaling tricks

Symbolic Regression Searches For An Equation

The third part of the talk moves from learning parameters inside a known model toward discovering equations. Symbolic regression asks for a readable expression that maps inputs to outputs. The challenge is that the space of possible formulas is enormous.

The speaker contrasts this with how scientists often work. Scientists do not usually search every possible formula at once. They form hypotheses, control variables, run purposeful experiments, and simplify the question until the hidden relationship becomes visible.

data pairs
huge formula space
controlled experiments
readable equation

Control One Variable To Reveal The Rule

The talk gives a simple example. If all variables change at once, the equation is hard to guess. But if one variable is held fixed, part of the formula becomes simpler. Then hold it at another value and compare the simplified formulas. The hidden role of that variable can become clear.

This is not a neural-network trick. It is an old scientific habit: change one thing at a time when possible, watch what changes, and use that contrast to infer cause. The talk turns that habit into a machine-learning strategy for symbolic regression.

hold one variable fixed
learn simpler relation
change the fixed value
assemble full equation

The Snowflake Example Shows Why Order Matters

The final example uses a phase-field model that grows a snowflake-like dendritic pattern. If all parameters are learned at once, the learned system can still make a dendritic shape but with the wrong structure. The number and shape of the branches can be wrong.

With a controlled learning schedule, the model first learns the parameters that matter in a simpler setup, then learns the other parameters once the first part is stable. The result is closer to the true snowflake pattern. The lesson is that the order of learning can matter when the equation has interacting pieces.

phase-field snowflake
learn all at once
wrong branch structure
controlled learning fixes it

Missing Variables Remain A Hard Problem

In the discussion, the question of missing variables comes up. A model may fail not because of random noise, but because some hidden cause is not being measured. The speaker notes that this would show up as a systematic deviation between prediction and experiment.

This is a major boundary. If the experiment does not measure an important cause, the learning system may fit the wrong equation. A good discovery system must eventually notice when its errors have a pattern that suggests a missing physical mechanism.

model predicts
experiment disagrees
error has a pattern
hidden cause may be missing

Why This Matters For Design And Topology

Design and topology problems often depend on evolving shapes, interfaces, and boundaries. In materials, that can mean voids, grains, cracks, pores, precipitates, or phase fronts. In engineered structures, it can mean where damage starts, where heat moves, where material changes phase, or where a boundary becomes unstable.

This lecture matters because it shows how a design workflow could learn from images or experiments directly, not only from clean simulation files. If a new alloy, lattice, porous material, or coating is tested under stress, heat, or irradiation, the method points toward a loop where the experiment teaches the state variables and the governing law.

The topology lesson is also clear: when the important action sits on interfaces, the model should spend attention there. A design surrogate that treats every grid point equally may waste effort. A better surrogate looks for where the geometry changes and where the physical law is active.

observe evolving geometry
learn interface law
predict design response
choose stronger topology

The Chapter In One Chain

First, microscope experiments can produce far more data than people can annotate by hand. Second, the scientific goal is not only tracking objects but discovering the physical law behind their motion. Third, a recognition network turns experimental images into physical state variables. Fourth, a neural differential equation model predicts how those variables evolve. Fifth, training makes annotations, recognition, and physics simulation agree. Sixth, black-box prediction may track current frames but fail when rolled forward because it does not know what futures are physically allowed. Seventh, interface problems are sparse because most change occurs near boundaries. Eighth, random projection uses that sparsity to compress the learning problem. Ninth, this scaling trick is justified by physical structure, not by convenience alone. Tenth, symbolic regression searches for readable equations, but the formula space is huge. Eleventh, controlled-variable experiments simplify the search by revealing one relationship at a time. Twelfth, the snowflake example shows that learning parameters in the right order can recover the right pattern when all-at-once learning fails. Thirteenth, missing variables remain a boundary because systematic error may mean a hidden cause is absent from the model. Fourteenth, design and topology benefit when experiments can teach laws for evolving interfaces, not just provide pictures.

The chapter's core idea: scientific discovery from data should not stop at recognizing a pattern. It should turn raw observations into physical variables, use a model that can be run forward, exploit where the physics actually changes, and use controlled experiments to make the hidden equation easier to find.

How To Test Whether You Understood This Chapter

Explain why tracking is not enough Tracking says where the void or boundary is now. Scientific discovery asks why it moves and what equation can predict what happens next.
Explain the two networks The recognition network turns noisy images into physical state variables. The physics network takes those variables and predicts their later state, so training can make video evidence and simulated evolution agree.
Explain why interfaces matter In voids, grains, cracks, and phase fronts, most change happens near boundaries. That sparsity gives a reason to compress the loss with projection instead of spending equal effort on quiet grid points.
Connect this to topology and design Many topology problems are really questions about evolving interfaces: where damage grows, heat fronts move, cracks spread, or material phases change. A useful surrogate should learn those interface laws from evidence, not only memorize final shapes.
