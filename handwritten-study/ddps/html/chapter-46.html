Use Machine Learning Where Scale Information Gets Lost

Read This Chapter As One Claim

Machine learning is useful in multiscale modeling when it becomes the disciplined bridge between a small-scale truth and a large-scale equation. The learned piece must summarize what the large model removed, not behave like a loose black-box shortcut.

Everyday problem Atoms, molecules, eddies, fibers, or polymer shapes control the large behavior, but carrying all of that detail inside the large simulation is too expensive.
Shared promise Use lower-scale simulations as expensive teachers, physics as structure, and concurrent learning to build a missing force law, closure, constitutive term, or material relation.
Hidden danger A fast learned term can fail if it ignores symmetry, extensivity, molecular shape, uncertainty in unexplored states, or the equation it must live inside.
First rejection test Reject the learned bridge if it cannot explain what lower-scale evidence supports it, what physics constraints it respects, and where active learning still finds uncertainty.

This chapter uses video 49, Weinan E's DDPS talk on machine learning and multiscale modeling. The talk is not about using a neural network because it is fashionable. It is about a long-standing modeling problem: small-scale physics contains the truth we need, but large-scale simulations cannot afford to carry every small-scale detail.

The first-principles question is simple. If atoms, molecules, eddies, or fibers control the large behavior, how do we pass only the needed small-scale information upward without inventing an unreliable hand-made rule?

fine-scale physics
too expensive to run everywhere
large-scale model needs missing term
ML estimates the scale bridge

Why Multiscale Modeling Hits A Wall

Many scientific models form a ladder. Quantum mechanics sits below density functional theory. Molecular dynamics sits below coarse-grained molecular dynamics. Those sit below continuum mechanics, fluid equations, solid mechanics, and turbulence models.

Every step up the ladder removes detail. That is necessary because the full lower model is too expensive. But the removed detail does not disappear from reality. It reappears as a missing modeling term: a potential energy function, an exchange-correlation functional, a constitutive law, a closure model, an equation of state, or a turbulence model.

quantum or molecular truth
coarse model removes detail
missing term must summarize detail
macro simulation becomes possible

The Old Choices Were Both Painful

One old choice was to write an empirical rule by hand. That can be fast, but it may fail when the material, molecule, flow, or operating condition changes. A hand-fit potential for one material may not be reliable for another. A hand-made turbulence or non-Newtonian fluid model may work in one setting and break in another.

The other old choice was to call the expensive lower-scale model directly. That can be more faithful, but it can be impossibly slow. For atomistic systems, density functional theory can compute accurate forces, but doing that inside every molecular-dynamics time step for huge systems is too expensive.

hand-made macro rule
fast but unreliable
direct fine-scale calculation
reliable but too expensive

Machine Learning Is The Missing Estimator

The speaker's claim is that machine learning helps exactly where older multiscale methods lacked a strong tool: extracting high-dimensional information from small-scale simulations and turning it into a usable large-scale model.

This is not the same as fitting a curve for display. The aim is an interpretable and reliable physical model. In plain terms, the learned piece should become something a scientist can put inside a simulator and defend: this is the force law, this is the closure term, this is the constitutive update, this is the equation term produced from lower-scale evidence.

lower model generates evidence
ML learns compact relation
physics constraints shape it
new physical model term

Sequential Learning Is Not Enough Here

In ordinary machine learning, someone often collects the data first, then another person trains a model on that fixed pile. The talk calls that sequential learning. Multiscale modeling needs something more active because each labeled data point can be very expensive.

The model must learn while deciding what evidence to buy next. Run a simulation. Notice where the current model is unsure. Ask the expensive lower-scale model for labels only there. Retrain. Repeat. This is the practical meaning of concurrent learning in the talk: data generation and model training happen together.

train current model
explore new states
label only uncertain cases
retrain and repeat

Deep Potential Molecular Dynamics From Zero

The first main example is molecular dynamics. The atoms move according to Newton's laws, but Newton's laws need forces. The hard part is the potential energy function: it tells the atoms what energy they have at a given arrangement, and forces come from how that energy changes.

Empirical potentials are cheap but can be unreliable for metals, semiconductors, alloys, chemistry, and bond breaking. Density functional theory is more reliable, but too expensive to call at every time step for very large systems. Deep potential molecular dynamics changes the bargain: use density functional theory as an expensive teacher, train a machine-learned potential, then run molecular dynamics with that learned potential.

DFT gives accurate labels
labels are expensive
learn energy and forces
run large MD cheaply

The Learned Atom Model Must Be Extensive

A molecular model trained on a thousand atoms should not be trapped at a thousand atoms. If the real simulation has a million atoms, the learned rule must extend naturally. That is why the model is built as a sum of local atomic energy contributions.

In everyday words, each atom looks at its local neighborhood. A small network estimates that atom's contribution to the total energy. Add the contributions from all atoms. This makes the model scale with the number of atoms, instead of being a fixed-size predictor that only works for one system size.

one local neighborhood
one atomic energy contribution
sum over all atoms
works for larger systems

Symmetry Is Not Decoration

The talk spends time on symmetry because it is a trust requirement. If we shift the whole molecule, rotate it, or relabel identical atoms, the energy should not change. A model that gives a different energy after a harmless relabeling has learned a coordinate accident, not physics.

A crude way to force symmetry can look good on test points and still fail in long molecular dynamics. The talk gives the reason: small discontinuities appear when atoms enter or leave a local neighborhood or when their ordering changes. A tiny discontinuity may not hurt a static test, but over many time steps it can make total energy drift.

shift, rotate, or relabel
energy should stay the same
bad symmetry causes drift
physics-shaped features fix it

Expensive Labels Must Be Bought Carefully

Each labeled molecular configuration requires an expensive quantum-mechanics calculation for energy and forces. So the training set has two jobs that fight each other. It must be broad enough to cover the situations the simulation will meet, and it must be small enough to afford.

The exploration-labeling-training loop solves this like a careful experiment. Explore configurations. Use an ensemble of learned models to see where predictions disagree. Large disagreement means the model does not know that region well. Label those cases with density functional theory. Then train again.

explore configurations
ensemble disagreement
DFT labels only needed cases
accurate smaller data set

The Aluminum-Magnesium Example Shows The Point

For an aluminum-magnesium alloy, the exploration process produced roughly half a million configurations, but the labeling procedure needed fewer than twenty thousand expensive labels. The goal was not to label everything. The goal was to label enough of the right cases.

This is the practical value of concurrent learning. It turns the expensive lower-scale solver into a teacher that speaks only when the student is uncertain. That can make atomistic simulations far larger while keeping accuracy close to the quantum-mechanics teacher.

many explored configurations
few need labels
quantum teacher fills gaps
large alloy MD becomes practical

The Water And Materials Examples Show Why It Matters

The talk mentions water, battery materials, high-entropy alloys, organic chemistry, biomolecular modeling, oxidized surfaces, and large-scale atom simulations. The common issue is the same: if the force model is weak, the later science is weak.

For water, the learned potential was used to reproduce important phase behavior. For large atom simulations, the approach helped move from thousands of atoms toward enormously larger systems. The big idea is not merely speed. It is using speed after the model has been trained against a more faithful lower-scale source.

water phase behavior
battery and alloy materials
biomolecular and chemistry systems
larger faithful simulations

The Second Example Is Polymer Fluid Closure

The next scale is larger than atoms. The speaker discusses non-Newtonian fluids, especially polymer solutions. These are fluids whose stress does not behave like plain water. Long molecules stretch, rotate, and remember the flow, so the large-scale stress depends on molecular shape and motion.

Classical models use hand-made closure rules. They introduce quantities such as a conformation tensor, which is a compact description of how polymer molecules are stretched or oriented. But then the model needs an equation for how that tensor changes, and unknown bracket terms appear. Those unknown terms are the closure problem.

polymer molecules move
macro flow needs stress
closure terms are unknown
learn them from micro model

Closure Means Summarize What Was Removed

Closure is one of the most important words in this area. It means the large-scale equation contains a term that depends on small-scale details the large-scale model no longer tracks. To close the equation, we must express that missing term using the variables the large-scale model does keep.

For the polymer fluid, the kept variable may be a conformation tensor. The missing term is learned from a microscopic model of the polymer. This is different from blindly searching all possible equations. The starting point is the underlying microscopic physics, and machine learning fills the bracketed terms that formal derivation cannot express cleanly.

micro detail removed
macro variable kept
missing bracket term
learned closure completes equation

Molecular Shape Changes The Large Flow

The polymer examples show why this matters. A dumbbell molecule, a chain molecule, and a star-shaped molecule can produce different large-scale flow behavior. If the closure model cannot feel molecular shape, it cannot make reliable predictions for a new polymer design.

The learned non-Newtonian fluid model captures stress and velocity behavior better than simpler classical models in the examples described. The practical lesson is that small shape differences at the molecular scale can become large stress differences at the flow scale.

dumbbell, chain, or star molecule
different stretch response
different stress history
different macro flow

This Is A New Physical Model, Not Just A Speed Trick

The speaker insists that the result should be viewed as a new physical model. That is a high bar. It means the learned piece must respect physics, be tied to lower-scale evidence, fit inside known equations, and remain testable.

A useful analogy from the talk is the equation of state for real gas. Engineers have long used tables or fitted functions inside larger equations. Here the fitted function is more complicated and may be represented by a neural network, but the role is similar: a lower-level or experimental source supplies a missing physical relation that the large-scale simulator needs.

known governing equation
missing relation
learned from faithful evidence
usable model component

How This Connects To Design And Topology

Design and topology optimization often depend on material laws. If the material law cannot feel molecular structure, crystal structure, polymer shape, alloy composition, or microstructure, then the optimized design may be optimized for the wrong material behavior.

This chapter says the design loop needs a credible scale bridge. For topology, the bridge might connect microstructure to stiffness, failure, damping, heat flow, or stress history. For materials design, it might connect atomistic or molecular choices to continuum properties. For manufacturing, it might connect processing choices to the effective law used by the part-level simulation.

microstructure or molecule
learned scale bridge
part-level simulation
design claim gets stronger

The Chapter In One Chain

First, multiscale modeling exists because small-scale physics controls large-scale behavior, but carrying every small detail is too expensive. Second, each step up the model ladder creates missing terms such as potentials, closures, constitutive laws, turbulence models, and equations of state. Third, old hand-made terms can be fast but unreliable, while direct lower-scale simulation can be reliable but too expensive. Fourth, machine learning can serve as the data-estimation tool that older multiscale algorithms lacked. Fifth, the learned term must be interpretable, reliable, and constrained by physics, not just accurate on a test set. Sixth, deep potential molecular dynamics uses quantum calculations as expensive labels to learn energy and forces for larger molecular dynamics. Seventh, the atom model must be extensive and respect translation, rotation, and permutation symmetries. Eighth, concurrent learning explores configurations, labels only uncertain cases, and retrains until the model is good enough. Ninth, polymer-fluid closure shows how machine learning can fill missing terms in a larger-scale equation derived from microscopic physics. Tenth, for design and topology, the point is to build material and flow laws that carry lower-scale evidence into part-scale decisions.

The chapter's core idea: machine learning helps multiscale modeling when it is used as a disciplined bridge between scales. The lower-scale model supplies evidence, physics supplies structure, uncertainty chooses new data, and the final learned term must behave like a usable physical model.

How To Test Whether You Understood This Chapter

The detailed truth is too expensive to use every time. The large model needs a compact rule that carries the important part of that truth forward.

Explain closure in one sentence

Closure means writing the missing effect of removed small details using the variables the large equation still keeps.

Connect it to topology and design

State the honest limit
