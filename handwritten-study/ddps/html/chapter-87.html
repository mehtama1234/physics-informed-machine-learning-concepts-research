Narrative chapter

Read Cell Choices Through A Transport Law

This chapter uses video 90, Krishna Garikipati's DDPS talk on Fokker-Planck inverse reinforcement learning. The talk starts with cancer cells moving in scratch assays, then builds a bridge from transport PDEs to agent-based decision language.

The first-principles question is this: when we watch many cells move, can we infer what kind of motion rule or hidden "reward" is shaping their behavior without pretending every cell is identical?

The lecture's answer is to start with the population-level transport law, use weak-form sparse system identification to discover advection, diffusion, and reaction terms, then move to a Fokker-Planck inverse reinforcement learning view when cell behavior is too heterogeneous for one mean-field description.

Read This Chapter As One Claim

Start with the movie, not the equations. A sheet of cells has a gap, and over time the gap fills. From far away that looks like ink spreading in water, so a field law can be enough: the population drifts, spreads, and grows. But then the biology becomes harder. Some cells follow a chemical signal, some move against it, and some behave uncertainly. At that point, one average flow can hide the thing we care about most: which hidden cell state makes one behavior more likely than another. This chapter says to change the level of description when the evidence demands it. Use a transport law when the crowd behaves like a crowd. Use an agent view when the individual choices matter. Fokker-Planck inverse reinforcement learning is the bridge between those two views: it uses a physics law for probability flow, then translates that flow into simple decision words like state, action, policy, and reward.

Shared promiseDense behavior can be read as transport, while mixed behavior can be read as many agents making probabilistic choices.
Hidden dangerA single average PDE can erase rare or resistant subpopulations, and fixed clusters can freeze behavior that should change over time.

A Scratch Assay Is A Transport Experiment

In a scratch assay, a layer of cells is cut to create an empty wound-like gap. Then the experimenter watches cells move into the gap. From far away, the movie looks like material transport. Some cells drift into the gap. Some wander randomly. Some divide and create new cells.

That is why the first mathematical language is advection, diffusion, and reaction. Advection means directed motion. Diffusion means random spreading. Reaction means birth or death of cells. The cell density changes because all three can happen at the same time.

wound gap opens
directed motion enters gap

division changes density

The Kymograph Shows Time And Space Together

The talk averages or slices the movie so the vertical axis is position and the horizontal axis is time. This plot is a kymograph. Early on, the middle gap has low cell density. Later, the gap fills.

The contours look close to a power law with an exponent near one half. That is a clue that diffusion may dominate, because classical diffusion spreads like the square root of time. But a clue is not enough. The lecture then asks for a more quantitative discovery of the PDE terms.

position on vertical axis
time on horizontal axis

System Identification Chooses The PDE Terms

The model library contains possible terms: diffusion, advection, reaction, and position-dependent coefficients. The method asks which terms are actually needed to explain the observed cell density.

This is done in weak form. Instead of differentiating noisy data directly at every point, the equation is tested against smooth functions and assembled like a finite-element residual. Then the unknown coefficients are chosen so the residual is small, with parsimony rules that remove unnecessary terms.

candidate PDE terms
weak finite-element residual
fit coefficients
remove unused terms

The First Result Is Mostly Diffusion

For the dense scratch-assay data, the inferred model reproduces the observed density fairly well. The discovered diffusivity is mostly steady with some bursts. The advection measure is mostly near zero with some local bursts. The reaction measure is very small.

So the early visual clue was basically right: this wound-closing movie is largely diffusion dominated. The value of the method is that it does not merely eyeball the movie. It separates the possible mechanisms and gives a principled estimate of which ones matter.

A Chemical Gradient Reveals Cell Heterogeneity

The next experiment adds a chemoattractant gradient. Many cells move toward the chemical signal, but not all of them do. Some move the opposite way. Some wander uncertainly.

This is not just random mess. In cancer biology, heterogeneous response matters because treatment may suppress one behavior while allowing a different subpopulation to survive and expand. The cells that do not follow the majority can become the hard part of the disease.

chemical gradient
some cells follow it
some move against it
heterogeneity matters

Three Clusters Are Helpful But Not Enough

The talk uses K-means clustering and finds three dominant behavior groups: one moving left, one moving right, and one less certain. A mean-field advection-diffusion model can be fit to each group, and it correctly picks up the average drift directions.

But this starts to break down. Each subpopulation is sparse. A smooth density field becomes shaky when only a few hundred cells are spread over a large region. More importantly, forcing a cell to belong to one fixed group at the beginning is too rigid. Real cells can change behavior as they move.

Cells Become Agents

The next step is to treat each cell as an agent. An agent has a state, takes an action, and moves to another state with some probability. In reinforcement learning language, the policy says which action is likely in a given state. The reward describes what the agent seems to be trying to gain.

For cells, we do not know the reward. We only observe trajectories. That makes the problem inverse reinforcement learning: from observed behavior, infer the hidden reward or value structure that could have produced it.

cell state
cell action
transition probability
hidden reward

Plain Inverse Reinforcement Learning Needs A Transition Model

Standard inverse reinforcement learning often assumes a transition function or estimates it empirically by counting observed moves. That is weak for extrapolation. If the transition is only a table learned from the observed trajectories, it has little reason to behave well outside those exact observations.

The talk asks whether mechanics can give a better transition model. This is where the Fokker-Planck equation enters.

observe trajectories
need transitions
counting is empirical
physics can help

Fokker-Planck Turns Density Motion Into A Potential

A normalized cell concentration can be viewed as a probability density. The Fokker-Planck equation describes how that density evolves under drift and diffusion. Its drift can be written through a potential, and that potential shapes where probability tends to move.

The key idea is that this potential plays a role similar to a value function in reinforcement learning. In the PDE, the potential drives the density. In the decision model, the state-action value guides what the agent does. The talk presents this as a conjectured structural connection, not as a finished theorem.

The First IRL Attempt Was Too Rigid

The first approach uses the three clusters as discrete actions. A cell effectively chooses at the beginning whether it belongs to the left-moving group, right-moving group, or uncertain group. The inferred rewards and policies reflect those groups.

That is useful but unsatisfying. It bakes too much of the answer into the setup. The cells cannot change action continuously, and they cannot change their minds on the fly. The later method fixes this by putting state and action into one continuous space.

Continuous State-Action Space Is The Better Model

The improved model treats state and action as a joint continuous space. The Fokker-Planck equation is then written over that larger space. From the inferred potential, the method gets the value function, the policy, the transition probabilities, and finally the reward through an inverse Bellman relation.

This is the heart of Fokker-Planck inverse reinforcement learning. The PDE supplies the mechanistic probability flow. The reinforcement-learning language translates that flow into reward, policy, action, and decision terms.

continuous states and actions

derive policy and transition
recover reward

Synthetic Data Checks The Machinery

Before applying the full method to cells, the talk tests it on synthetic data where the ground-truth reward and value function are known. The inferred reward and value function match the ground truth reasonably, and distribution error declines as the method improves.

This matters because the biological case is hard to interpret directly. A synthetic check proves that the pipeline can recover known hidden structure before asking it to interpret real cell behavior.

The Biological Actions Are Kinase Levels

For the real cancer-cell data, the state is cell velocity. The actions are not fixed cluster labels. They are continuous expression levels of two kinases: AKT and ERK. These molecular signals are related to cell motion.

The method asks whether certain kinase-expression choices are associated with higher reward for certain movement states. This connects motion and molecular state in one inferred decision landscape.

state is velocity

action is ERK level

The Result Points To Low AKT And High ERK

The inferred reward is higher for cells moving in the expected chemoattractant direction. Inside that reward landscape, the action values suggest low AKT and high ERK are associated with the higher-reward movement pattern.

The biology check is important. Collaborators had intervention data. Knocking down ERK reduced motion. Knocking down AKT gave slightly larger trajectories. That matched the inferred pattern: high ERK and low AKT support stronger movement in this setting.

The Q And A Names The Limits

The Q&A makes two limits clear. First, the continuous state-action method is much more expensive than the discrete cluster method because it works in a higher-dimensional space. Second, sparse model discovery depends on the candidate library. If the library only includes polynomial terms up to a certain order, the method cannot discover terms outside that library.

There is also a numerical caveat in the early inferred fields: some stripe artifacts came from time-step or numerical choices. These details matter because the method is powerful, but it is still an inference pipeline with modeling, discretization, and library choices.

Why This Matters For Design And Topology

At first, this may look far from topology. It is not. Topology and design are about structure in space: where cells move, where material appears, where voids close, where agents concentrate, and how a population changes its layout over time.

The scratch assay is a topology-changing field: an empty gap fills with cells. The chemoattractant experiment is a design field: an imposed gradient reshapes the population. Fokker-Planck inverse reinforcement learning asks what hidden reward landscape could explain those changes.

For broader scientific design, the lesson is to choose the level of description carefully. Dense populations may support PDE discovery. Sparse heterogeneous populations may need agent-based interpretation. If a design loop changes the environment, chemistry, geometry, or treatment, this kind of method can help identify which hidden action variables actually drive the population's response.

If they split into sparse and different behaviors, treat them as agents. Fokker-Planck inverse reinforcement learning is the bridge: probability flow gives a physics-shaped way to infer reward, policy, and action from observed motion.
