Learn The Missing Piece Inside The Simulator

This chapter uses video 93, Christopher Rackauckas's DDPS talk on generalizing scientific machine learning and differentiable simulation beyond continuous models. The talk is about universal differential equations, symbolic recovery, differentiable simulation, adjoints, chaotic systems, jump processes, and agent-based models.

The first-principles question is this: if we already know part of a scientific model, why should a neural network relearn everything from raw data?

The lecture's answer is to put the known model around the unknown part. Use the simulator as the body of the model. Put a flexible function approximator only where knowledge is missing. Train that missing piece through the simulator, then inspect it, simplify it, and use it as a clue about the science.

Read This Chapter As One Claim

Start with a simple rule: do not ask a neural network to rediscover what the science already knows. If you know rabbits grow, wolves die without food, infected people pass through epidemic compartments, cars cannot instantly spin, or heat is carried by a PDE, keep that knowledge in the model. Put the flexible learned part only in the empty slot: the unknown interaction, exposure rate, sensor correction, closure, or missing force. Then train that learned part while it is inside the simulator, because the simulator is where its mistakes become visible. The point is not to make the model sound more scientific. The point is to make the learning problem smaller, more testable, and more honest: the neural part should explain the missing piece, not replace the whole world.

Scientific Data Is Not Like Web Data

The talk starts by making a plain point. Scientific knowledge often exists as equations, constraints, conservation laws, mechanisms, or confirmed theories rather than giant data sets. General relativity is not a web-scale data set. It is a compact model supported by experiments.

Scientific machine learning should therefore use the model knowledge we already have. The data should teach the part we do not know, not force the model to rediscover every known law from scratch.

small data set

A Universal Differential Equation Has A Missing Function Slot

A universal differential equation is a differential equation with one or more flexible function approximators inside it. The approximator might be a neural network, polynomial expansion, Fourier series, or another flexible representation.

The point is not that the neural network is magic. The point is that the equation says where the unknown function belongs. The model structure narrows the learning problem from "learn all dynamics" to "learn this missing term."

differential equation
known terms stay fixed
unknown function slot
approximator fills slot

The Predator-Prey Example Gives The Basic Shape

Rackauckas uses a Lotka-Volterra-style story. If rabbits are alone, they grow. If wolves are alone, they decline. The missing piece is the interaction between rabbits and wolves. Instead of throwing away the known terms, put a neural network only in the interaction part.

After training, that neural network is a computational stand-in for the unknown interaction law. Because it sits inside an equation, we can take sensitivities, look at its Jacobian, and ask what it learned.

rabbits grow alone
wolves decline alone
interaction unknown
learn interaction term

Pure Neural ODEs Extrapolate Poorly

The COVID example starts with a pure neural ODE trained on early pandemic data. It fits within its short window but extrapolates badly. That is expected: a generic neural network does not know what an epidemic is.

Then the model is given the SEIRD structure: susceptible, exposed, infected, recovered, and dead. The unknown exposure term is learned by a neural network. This makes the model much more epidemic-shaped and improves extrapolation.

pure neural ODE
short training window
SEIRD structure added
learn exposure term

Structure Shrinks The Function Space

The epidemic structure does more than sound scientific. It mathematically restricts the allowed behavior. Susceptible people decrease. The infected curve has epidemic-like peak behavior. If the neural exposure term is forced positive, the whole model obeys useful qualitative constraints.

This is why less data can work. We are no longer searching all possible time-series functions. We are searching a smaller set of functions consistent with the scientific structure.

Symbolic Regression Turns A Learned Term Into A Hypothesis

After learning the unknown exposure term, the workflow probes the neural network and uses symbolic regression to express it with simpler mathematical pieces. In the COVID example, the recovered expression can reveal which variables matter and which do not.

This matters because the learned term becomes a scientific hypothesis. If exposure does not depend on the dead compartment, that is interpretable because dead individuals no longer expose others. The model is not merely predicting; it is suggesting a mechanism to check.

probe its behavior

More Correct Prior Model Means Less Data

The talk emphasizes a continuum. If we put in more correct model knowledge, we need less data to learn the missing piece. If we put in less model knowledge, the data must carry more burden.

There is no universal number of data points that makes a scientific ML model work. The data requirement depends on how much correct prior model structure was included and how much uncertainty remains in the unknown part.

Relativity Can Be Learned As A Correction

One example starts with Newtonian two-body mechanics and asks whether gravitational-wave data can teach the relativistic correction. The known Newtonian model is not thrown away. It becomes the base model, and the neural term learns the missing correction.

This is the same first-principles pattern again: do not learn black-hole motion from nothing if you already know Newtonian mechanics. Learn the part Newtonian mechanics misses.

Newtonian base model
gravitational-wave data
learn correction
better two-body motion

UDEs Can Encode Graph Structure, Not Just Equations

The epidemic example is revisited as a graph of compartments. Susceptible people become infected. Infected people recover or die. Susceptible people do not recover without infection. That graph structure alone is useful prior knowledge.

The model can place unknown neural functions on allowed flows between compartments. This lets the learner discover equations while obeying the graph of what can turn into what.

state graph known
allowed transitions only
neural rates on edges
recover equations with less data

Reaction-Diffusion Shows Local Chemistry Inside A Field

The chemical-reactor example couples a spatial reaction-diffusion PDE to a non-spatial ODE. The unknown part is the chemical interaction term. Although the data is spatiotemporal, the unknown chemistry is a low-dimensional local reaction function.

That transforms the learning problem. Instead of learning a whole future field from scratch, the model learns a small reaction law embedded inside the PDE. The PDE supplies the field behavior; the neural network supplies the missing chemistry.

spatiotemporal data
PDE transport known
reaction term unknown
learn local chemistry

The Recovered Equation May Be Locally Right, Not Identical

In the reaction example, symbolic regression may not recover the exact equation that generated the data. That does not automatically mean failure. The recovered expression can match the local Taylor behavior and preserve useful mechanistic features, such as self-interaction or cross-interaction terms.

The warning is important. Sparse recovery is not an oracle for the one true equation from finite data. It gives a simpler expression that can be scientifically useful if its behavior and limits are checked.

finite data
many possible formulas
local behavior matches
check before claiming truth

Formula 1 Shows Physics Fixing Sensor Hallucination

The Formula 1 example calibrates a speed-over-ground sensor against GPS data. A purely data-driven Gaussian-process model can produce physically impossible orientation wiggles, like a car changing direction faster than vehicle dynamics allow.

Adding a simple vehicle-dynamics model gives the learner a physical path. The unknown part is the sensor-to-dynamics relationship, not the entire motion of the car. The result is a smoother and more physically plausible estimate from the same data.

sensor data
pure GP wiggles
vehicle dynamics added
plausible orientation

Training Outside The Simulator Can Drift

The climate-closure example shows why differentiable simulation matters. One approach builds derivative labels from data, trains a neural closure outside the simulator, and then inserts it into the PDE. That can drift badly over time.

The reason is that the simulator itself creates numerical and accumulated errors. A closure trained only to match local derivative residuals has not learned how it behaves when integrated inside the simulator.

differentiate data
train closure outside solver
insert into simulator
long-time drift appears

Differentiable Simulation Trains Through The Actual Solver

The better approach solves the PDE with the neural closure inside it, compares simulated temperature with measured temperature, and differentiates through that solve to update the neural parameters.

This trains the closure in the environment where it will actually be used. In the talk's example, training through the simulator gives orders-of-magnitude better behavior than training on derivative labels outside the simulator.

neural closure inside PDE
solve simulator
compare output data
differentiate through solve

Adjoint Method Is Not One Method

Training through a simulator requires derivatives of simulator outputs with respect to neural-network weights. People often say "use the adjoint method," but the talk warns that there are many adjoint choices with different stability, memory, and compute tradeoffs.

The advection example explains why. A mathematically reversible ODE idea can become numerically unstable when applied to a discretized PDE with upwinding and downwinding. The derivative method has numerical properties just like the forward solver does.

UDEs Are A Software Pattern Too

The UDE view is also a software abstraction. If solvers for ODEs, SDEs, PDEs, nonlinear equations, linear solves, optimization problems, and integrals all connect to machine-learning tools, then a scientific model can be augmented by learned unknown functions wherever needed.

This is the SciML ecosystem idea in the talk: make differentiable scientific solvers reusable so that many different scientific ML methods become special cases of the same underlying pattern.

scientific solver

Beyond Continuous Models Means New Derivatives

The final part moves beyond ordinary ODEs and PDEs. Chaotic systems can make pointwise solution derivatives meaningless over long times, but derivatives of long-time or ergodic properties can still be meaningful.

Jump processes and agent-based models are also not smoothly differentiable in the usual sense. The talk describes a generalized idea: construct a new stochastic process whose expected value gives the derivative of the expected value of the original process. That makes it possible to train unknown rate functions even in discrete or stochastic simulations.

chaotic models
jump processes
agent-based models
generalized derivatives

Local Versus Nonlocal Closure Is A Modeling Choice

In the Q and A, the climate closure is clarified. The closure term was tested with both local and nonlocal inputs. The nonlocal version takes the full vector of average temperatures. The local version behaves more like a convolutional closure.

The nonlocal version performed better, which matches the mathematical expectation that the closure operator can depend on the wider state, not just one grid point. This is another example of the same theme: the architecture should match what the missing physics is allowed to depend on.

local grid input
nonlocal full vector input

architecture must match physics

Why This Matters For Design And Topology

Design and topology workflows often ask a model to evaluate cases outside the training examples. They may change geometry, material layout, sensor placement, reaction conditions, vehicle setup, or unresolved closures. A pure black-box surrogate may learn the training examples but violate the structure that makes a design physically possible.

This lecture gives a better pattern. Keep the known simulator, graph, conservation relationship, or transition structure. Learn only the unknown constitutive law, closure, correction, rate, sensor mapping, or interaction term. Train the missing term through the simulator when its effect is only visible after integration.

For topology, the key warning is that the optimizer will exploit whatever freedom the model gives it. If the neural part is outside the simulator, local, unstable, or differentiated with the wrong adjoint, the design loop can optimize an artifact. The learned part must be placed where the missing physics lives and trained under the same solver behavior the design will use.

The Chapter In One Chain

First, scientific knowledge often exists as models, not huge data sets. Second, scientific ML should use known laws and learn only missing pieces. Third, universal differential equations put flexible function approximators inside differential equations. Fourth, the predator-prey example learns an unknown interaction while keeping known growth and decay. Fifth, a pure neural ODE extrapolates poorly on early epidemic data, while a SEIRD model with a learned exposure term extrapolates better. Sixth, known structure shrinks the function space and lowers the data burden. Seventh, symbolic regression turns the learned unknown term into an inspectable hypothesis. Eighth, more correct prior model means less data is needed. Ninth, gravitational-wave, earthquake, graph-epidemic, reaction-diffusion, and Formula 1 examples show the same pattern across domains. Tenth, training a closure outside the simulator can drift once inserted into the PDE. Eleventh, differentiable simulation trains the learned term through the actual solver and observed outputs. Twelfth, adjoint methods are not interchangeable; their stability, memory, and compute properties matter. Thirteenth, UDEs also provide a reusable software pattern for scientific solvers plus learned unknown functions. Fourteenth, chaotic systems, jump processes, and agent-based models require generalized derivative ideas. Fifteenth, nonlocal closure can matter when the missing term depends on the wider state. Sixteenth, design and topology loops should learn unknown terms inside the simulator and verify the derivative and closure assumptions before trusting optimization results.

The chapter's core idea: do not train a black box beside the simulator and hope it behaves once inserted. Put the unknown function inside the scientific model, train it through the solver when needed, and then inspect what the learned term says about the missing physics.
