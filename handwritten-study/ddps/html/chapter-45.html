Narrative chapter

Find The Coordinates Before You Write The Equation

Read This Chapter As One Claim

Before learning an equation, first find the world the equation should live in. The useful variables, space, time order, and coordinates may not be given; they may have to be discovered from data before the physics becomes simple enough to model.

Everyday problem A detailed simulator or experiment can produce huge messy data, while the clean large-scale quantity needed for design, control, or prediction is hidden.
Shared promise Use lifting, restriction, manifold learning, delay coordinates, autoencoders, diffusion maps, and gray-box learning to find useful coordinates and learn only the missing rule.
Hidden danger The wrong observable can make a simple system look impossible, and many different equations can fit the same recorded data.
First rejection test Reject the learned equation if it cannot say what variables, space, time order, sensor distortion, and new test cases support its claim.

This chapter uses video 48, Yannis Kevrekidis's DDPS talk called "No Equations, No Variables, No Parameters, No Space and No time." The title sounds playful, but the problem is serious. Sometimes we can simulate a complicated system in tiny detail, yet we do not know the clean larger-scale equation that would let us reason, design, control, or predict cheaply.

The first-principles question is this: before asking a machine to learn an equation, do we even know what the equation should be about? Do we know the right measured quantity, the right small set of variables, the right notion of space, or even the right ordering of time?

The Whole Talk Starts With Two Pictures Of One System

Kevrekidis starts with microorganisms moving on the ocean surface. On one side there are many dots. Each dot is an organism. They move, die, reproduce, and get stirred by random currents. If you stare only at those dots, the system looks like noise.

On the other side he shows a pair correlation function. In plain words, it asks: for a typical organism, how many neighbors does it have at each distance? That one measured curve behaves smoothly. It can settle, change, and be studied like a larger-scale equation. Same system, different way of looking.

many random organisms
neighbor-count curve
smooth coarse motion
usable macro law

Equation-Free Means Ask The Simulator Only For What You Need

Suppose we believe a clean large-scale equation exists, but we do not know how to write it. A normal solver would need a large-scale starting state and a time derivative. The equation-free idea says: do not learn the whole equation first. Use the detailed simulator to estimate only the next number the large-scale solver needs.

The steps are concrete. Start with a coarse state such as the pair correlation function. Build many detailed particle arrangements that match that coarse state. Run the detailed simulator for a short burst. Measure the coarse state again. Estimate how fast the coarse state is changing. Then take a larger coarse step, as if the unknown large-scale equation had briefly answered your question.

coarse starting state
make matching particles
run a short burst
take a large coarse step

Lifting And Restriction Are The Two Doorways

The talk gives names to the two direction changes. Lifting means going from the large-scale description down to detailed simulator states. Restriction means coming back up from detailed simulator results to the large-scale measured quantity.

This is easy to say and often hard to do. If the coarse state says "this is the neighbor-count curve," there may be many particle arrangements that match it. The method works only if those detailed arrangements quickly settle onto the same large-scale behavior. If lifting creates the wrong kind of microscopic state, the estimated coarse derivative can be misleading.

coarse quantity
consistent detailed states
short simulator experiment
measured coarse response

Variable-Free Means The Right Quantity Is Not Known Yet

The plankton example worked because someone already knew that the pair correlation function was the right thing to watch. That is a huge assumption. In many systems we have the detailed data but do not know which summary makes the motion simple.

For particles, maybe the useful summary is density. Maybe it is velocity. Maybe it is a distribution shape. Maybe it is a neighbor-count curve. The wrong measured quantity can make a simple system look impossible. The right measured quantity can reveal a clean large-scale law.

raw data looks tangled
many possible summaries
wrong summary hides law
right summary makes motion plain

Manifold Learning Finds A Smaller Set Of Coordinates

A detailed snapshot can have thousands or millions of numbers. A useful description may need only a few. Manifold learning is the attempt to find those few coordinates from the data itself.

Kevrekidis names older and newer routes: principal components, autoencoders, isomap, locally linear embedding, and diffusion maps. The common idea is simple. Compare many high-dimensional observations. If they really lie near a lower-dimensional surface, find coordinates on that surface. Then write or learn the dynamics in those coordinates instead of in the original huge list of numbers.

huge snapshots
compare nearby cases
find low-dimensional surface
use the discovered coordinates

Learn The Dynamics After Finding The Variables

The talk then connects this to old neural-network work on time series. If measurements change over time, we can first build a small state from delay coordinates or an autoencoder. After that, a recurrent network or another time-stepping model can learn how that state moves.

The important point is not the brand name of the network. The important point is the job. Do not only learn "input now to output later" as a black box. Try to learn the thing a scientist wants: the rule of change, the right-hand side, the part that says how the state starts moving from where it is now.

measured time series
small hidden state
learn rule of change
forecast and analyze

Learn Only The Missing Part When Physics Is Partly Known

Sometimes we do not start from zero. We may know part of the equation and only lack a reaction term, a closure, a drift, a diffusion, or a force. The talk calls this a gray-box idea: keep the known part hardwired and learn only the unknown part.

This matters because it keeps the model honest. If diffusion is known, do not ask the network to rediscover diffusion from scratch. Spend learning capacity on the missing piece. That also makes the learned term easier to inspect, because the question becomes narrower: what gap did the known physics leave behind?

known physics term
unknown closure term
learn only the gap
clearer model claim

Learn PDEs From Space-Time Data

A partial differential equation connects change in time to nearby values in space. In everyday words, it says: what happens here next depends on what is happening here and nearby right now.

The talk explains that this shape matches a learning architecture. A convolutional network can look at nearby points in space. A recurrent or time-stepping network can move the result forward in time. The point is not that a neural network magically becomes physics. The point is that the learning setup can be shaped like the numerical method scientists already use.

space-time movie
look at local stencil
learn local time change
reuse as a PDE-like rule

Agent Simulators Can Teach Macro Laws

The bacterial chemotaxis example makes the same idea practical. The detailed simulator has thousands of bacteria. Each bacterium has internal states and random behavior. But the decision often does not need every bacterium. It needs the density of bacteria and how that density moves toward food.

So the detailed simulator becomes a teacher. Run the agents. Measure the density. Learn a large-scale equation for that density. If part of the law is already known, such as diffusion, keep that part and learn the chemotaxis part that points the bacteria toward food.

many bacteria agents
measure density over space
learn coarse chemotaxis law
analyze the population cheaply

No Space Means Recover The Coordinate Itself

This is the most important part for the bigger picture. Kevrekidis asks us to imagine a space-time simulation, then shred it into many time series. Each time series came from one spatial location, but the spatial order has been scrambled. We know what happened at each sensor, but not where that sensor belongs.

If neighboring places behave similarly, data can put the locations back in order. Each time series is treated as a data point. Similar time series are placed near each other. The learned coordinate can recover the topology of the original space, up to harmless flips or bends. The simple idea is: build a space where nearby behaviors live nearby.

shuffled local time series
compare behavior similarity
recover emergent coordinate
learn law in that space

Emergent Space Is A Place Where The Behavior Becomes Smooth

The recovered space does not have to be ordinary physical space. In the oscillator examples, the useful coordinate may be an intrinsic frequency or another hidden difference between units. In the neuron-network example, the useful coordinates relate to both the node dynamics and the network structure.

This is why the idea matters beyond one toy example. A messy network can sometimes be seen as a rough sample of a smoother hidden surface. Once the right coordinate is found, the behavior can look like a field changing over that hidden surface. Then tools for PDEs and operators become useful again.

messy network traces
hidden differences between units
data-driven space
smooth field-like behavior

No Time Means Recover The Order Of Events

The same puzzle idea can be turned sideways. Instead of scrambling locations, scramble the order of frames in time. Or cut the movie into small patches of space and time. If neighboring patches contain enough local information, data can help register them and rebuild a useful order.

This does not mean time is fake. It means the recorded data may not arrive with the useful order already labeled. In experiments, sensors, videos, and simulations, we may have fragments. The modeling task can begin by arranging the fragments into a space-time description where change is easier to learn.

shuffled frames or patches
compare local neighborhoods
register the fragments
recover useful order

Data Gauge Means Sensors Distort Distance

A learning method usually needs a distance: are these two observations close or far? That sounds simple until different sensors observe the same state through different distortions. One camera, one lab, or one learned encoder may stretch one direction and shrink another.

The data-gauge idea is to correct for those local distortions. Instead of comparing only raw points, look at small neighborhoods around each point and how those neighborhoods are stretched by the measurement. Then different views of the same phenomenon can be mapped toward a shared representation.

same state through different sensors
raw distance misleads
local neighborhoods reveal distortion
shared latent space

The Warning: Many Equations Can Fit The Same Data

The question period adds a key warning. Given the same data, there may be many equations that agree with it. One model may describe the data as an ordinary differential equation. Another may use an integral equation. Another may use a different operator entirely. Fitting the data does not prove that the chosen equation is the real one.

So the claim must be smaller and more testable. Say what the model predicts, under which initial conditions, over which range, with which variables, and what new case would make it fail. The right attitude is not "I found the equation." It is "I found a usable operator-shaped description that survived these tests."

same observations
many possible operators
test new conditions
claim only what survives

How This Connects To Design And Topology

In design, topology, materials, chemistry, and engineered systems, the hard part is often not just the solver. It is choosing the representation. Should the design be described by pixels, holes, struts, a graph, a material field, a microstructure state, a frequency coordinate, or a learned latent coordinate?

This chapter says: do not optimize in a bad coordinate system and then blame the optimizer. First ask what view makes the physics smoother. For topology optimization, that may mean learning a coordinate for shapes that keeps similar load paths near each other. For materials, it may mean learning a coordinate for microstructures where similar stress histories sit nearby. For agent systems, it may mean learning a density law instead of tracking every individual.

The Chapter In One Chain

First, a complex system may have a detailed simulator but no written large-scale equation. Second, equation-free computation asks the simulator only for the next coarse quantity a solver needs, such as a time derivative. Third, lifting creates detailed states that match a coarse state, and restriction measures the coarse state after a short detailed run. Fourth, this works only if the coarse variables are right. Fifth, variable-free modeling uses data to discover useful coarse variables when experts do not already know them. Sixth, manifold learning, autoencoders, diffusion maps, and related tools can turn huge observations into a few usable coordinates. Seventh, after the variables are found, learning can target the rule of change, a missing physics term, or a PDE-like operator. Eighth, if physical space is missing or scrambled, similarity of behavior can recover an emergent coordinate where the behavior becomes smoother. Ninth, if time or space-time fragments are scrambled, local patches can sometimes be registered into a useful order. Tenth, every learned coordinate and equation must be tested beyond the data because many different operators can fit the same observations.

The chapter's core idea: before writing or learning an equation, ask what world the equation should live in. The useful variables, space, time, and operator may all have to be discovered from data, and each discovery needs a test.

How To Test Whether You Understood This Chapter

Say the problem without equation words

You may be measuring the wrong thing. First find the view where the messy motion becomes a simple story, then learn the rule in that view.

Explain lifting and restriction

Lifting builds detailed states that match a coarse description. Restriction measures the coarse description after the detailed simulator runs. These are the doorways between the two levels.

Connect it to topology and design

A topology problem may be hard because pixels or raw geometry are the wrong coordinates. A better coordinate can keep similar load paths, material states, or microstructures near each other, making design changes easier to reason about.

State the honest limit

Finding coordinates is not proof that the discovered equation is true. The model must survive changed initial conditions, changed ranges, sensor distortions, and comparisons against other possible operators.
