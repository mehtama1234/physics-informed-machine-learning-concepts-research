Narrative chapter

Learn The Missing Closure From Indirect Evidence

This chapter uses video 92, Jin-Long Wu's DDPS talk on data-driven closure modeling using derivative-free Kalman methods. The talk is about what to do when a reduced model is cheap enough to run but is missing the effect of scales or physics that were thrown away.

The first-principles question is this: if we cannot simulate every detail of a complex system, and we also cannot directly observe the missing term, can we still learn a useful closure from the response we can measure?

The lecture's answer is yes, but with care. Treat the missing closure as an unknown correction. Push guesses of that correction through the forward model. Compare the predicted observable response to the measured response. Use ensemble Kalman inversion to update the closure without needing gradients of the forward solver.

Read This Chapter As One Claim

Start with the trade. A full simulation may contain every small swirl, eddy, molecule, or hidden coordinate, but it is too expensive to use in design. So we keep a cheaper model and throw away the details. The thrown-away details do not vanish; they still affect the part we kept. A closure is the name for that missing push. The hard part is that we usually cannot measure the closure directly. We only see consequences: a few velocity readings, averaged statistics, or a long-term distribution. This chapter says to learn the missing push by making guesses, running the reduced model forward, and keeping the guesses that make the observable behavior match. But the match must be tested hard, because a flexible closure can explain the few measurements while giving the wrong long-time dynamics or the wrong design answer.

Closure Exists Because We Throw Details Away

Complex dynamical systems such as climate, turbulence, multiscale materials, and engineering flows contain many interacting scales. Simulating every small detail can be impossible. So engineers choose a reduced state: the part they can afford to simulate.

The problem is that the unresolved part does not stop mattering. It still pushes on the resolved part. A closure model is the term that tries to represent that missing push using only the resolved variables.

Direct Closure Labels Are Often Not Available

The easiest training data would be direct pairs: a reduced state and the true closure value at that state. But getting that direct closure value usually requires temporal derivatives from noisy data or access to the full high-fidelity system state.

Both are hard. Noisy or sparse time data makes derivatives unreliable. Full simulations can be too expensive. So the talk focuses on indirect data: observations of the resolved state, such as sparse velocity measurements or time-averaged statistics.

want state-to-closure labels

full simulation is costly

Ensemble Kalman Inversion Updates Guesses

Ensemble Kalman inversion starts with a collection of parameter guesses. Each guess is pushed through the forward map. The predicted data is compared with the observed data. The mismatch is projected back into parameter space to update the guesses.

The important practical feature is that the method is derivative-free. It only needs forward model evaluations. That matters when the forward model is a complicated solver where gradients are unavailable, awkward, noisy, or expensive.

sample parameter ensemble
run forward solver
compare with data
update without gradients

Turbulence Closure Is The First Example

The first application is Reynolds-averaged turbulence modeling. RANS simulations are widely used because they are cheaper than resolving all turbulent motion, but their Reynolds-stress models can be inaccurate for complex flows.

The missing closure is the discrepancy between the true Reynolds stress and the modeled Reynolds stress. If we can infer that discrepancy field, we can correct the RANS model and improve the velocity prediction.

RANS is affordable
Reynolds stress is wrong
infer discrepancy field
improve velocity prediction

Sparse Velocity Data Can Infer A Full Stress Correction

The example is flow over periodic hills. The available measurements are sparse velocity observations at selected locations. The unknown is the full-field Reynolds-stress discrepancy.

The algorithm samples possible discrepancy fields from a prior, runs the RANS solver, compares predicted velocity to sparse observations, and updates the discrepancy field. The posterior velocity profiles move closer to the direct numerical simulation reference, especially in difficult recirculation regions.

periodic hill flow
sparse velocity sensors
update stress discrepancy
better recirculation result

The Prior Encodes Smoothness And Where Error Is Likely

The discrepancy field is given a Gaussian-process prior. A squared-exponential kernel encourages smooth sampled fields. The variance is made larger in regions where the baseline RANS model is expected to perform poorly, such as shear and recirculation regions.

Then a Karhunen-Loeve expansion provides basis functions. The closure field becomes a linear combination of those basis functions, and the inversion estimates the coefficients. This is useful but also limiting: if the basis cannot represent the true discrepancy, the posterior cannot reach the exact truth.

Sparsity Prevents A Closure From Explaining Too Much

The second part of the talk adds sparsity to ensemble Kalman inversion. The reason is simple: if data is indirect and limited, a flexible model can overfit the observed statistics while learning the wrong dynamics.

The method uses the fact that each EKI update can be viewed as an equivalent convex optimization problem. An L1 constraint can then be added to push redundant coefficients toward zero. The implementation uses auxiliary positive and negative variables so the constraint becomes a standard quadratic programming problem.

limited indirect data
many candidate terms

The Kuramoto-Sivashinsky Test Shows The Overfit

The sparse-EKI example uses the Kuramoto-Sivashinsky equation. The model does not know the right-hand-side terms and is given redundant basis functions. The data is not a full time series; it is time-averaged information such as moments, autocorrelation, and spatial correlation.

Standard EKI can match the data space but still produce wrong long-time behavior when the calibrated system is simulated. Sparse EKI pushes redundant coefficients near zero and gives a system whose evolving profile agrees much better with the true system.

Some Closures Should Be Stochastic

The final part goes beyond deterministic closures. If unresolved scales are clearly separated from resolved scales, their aggregate effect may look simple. But many complex systems do not have clean scale separation. Then unresolved dynamics can act like noise on the resolved model.

A stochastic closure adds both a deterministic correction and a noise term. The task becomes learning the drift correction and the diffusion or noise amplitude from indirect data.

no clear scale separation
unresolved dynamics fluctuate
deterministic correction
stochastic noise term

Noisy Lorenz Shows Why Matching Data Is Not Enough

The first stochastic example is a noisy Lorenz-63 system. The model has missing deterministic terms and an unknown diffusion coefficient. The method learns both using time-averaged data.

A deterministic-only closure and a stochastic closure can both match the available data space. But when simulated for a long time, their invariant measures differ. The stochastic closure matches the true long-term distribution much better. This is a key lesson: matching short or averaged data does not prove the long-term dynamics are right.

A Reduced Lorenz Model Needs Noise To Restore Chaos

The second stochastic example starts from a reduced Lorenz setting. A coordinate with only a small amount of energy is removed. The reduced deterministic system loses the chaotic behavior of the original system.

Earlier work showed that adding white noise can qualitatively restore chaos. This talk goes further: learn both deterministic and stochastic closure terms from averaged data so the reduced model recovers the long-term behavior of the retained variables more quantitatively.

The Q And A Names The Scaling Limits

The Q and A clarifies that EKI is ensemble-based, so forward evaluations can often be parallelized. The expensive piece appears when the data space is high-dimensional because the update involves matrix inversion in data space.

For high-dimensional data, localization can help. Localization means keeping better-estimated short-range covariance information and thresholding unreliable long-range covariance entries, making the matrix sparse. The talk also notes that Gaussian priors are chosen partly for smoothness and computational convenience; if a non-Gaussian prior is physically justified, one can map Gaussian random variables through a generative model to produce non-Gaussian samples.

Why This Matters For Design And Topology

Topology and design workflows often use reduced models. A designer may remove small scales, use coarse meshes, average turbulence, ignore unresolved geometry, or replace a full model with a lower-dimensional state. Every one of those choices creates a closure question: what did the reduced model throw away that still matters?

This lecture gives a practical design lesson. Do not require impossible labels for the missing term. Use the measurements you can get: sparse sensors, averaged statistics, long-term distributions, or output fields. But also guard against overfitting those indirect measurements. Sparsity, priors, stochastic terms, and long-term checks are not decoration; they are what keep the closure from becoming a curve fit.

For topology optimization, the warning is direct. A closure learned only to match a few observed quantities may make the optimizer trust the wrong flow separation, wrong turbulence stress, wrong long-term attractor, or wrong unresolved-scale effect. A useful closure must be checked where the design decision actually depends on it.

The Chapter In One Chain

First, complex systems contain too many scales to simulate every detail. Second, a reduced state is cheaper but loses information. Third, a closure represents the influence of unresolved scales on resolved variables. Fourth, direct closure labels are often unavailable because derivatives are noisy and full simulations are costly. Fifth, indirect data such as sparse velocity observations or time-averaged statistics can still constrain the closure. Sixth, ensemble Kalman inversion updates closure parameters by running the forward model and comparing predicted observations with real observations. Seventh, the method is derivative-free, which helps when the forward solver is complicated. Eighth, turbulence closure uses sparse velocity data to infer a full Reynolds-stress discrepancy field. Ninth, Gaussian-process priors and Karhunen-Loeve bases encode smoothness and likely error regions but also limit what can be represented. Tenth, sparse EKI adds an L1 constraint to avoid overfitting limited indirect data. Eleventh, the Kuramoto-Sivashinsky example shows that matching averaged data is not enough if redundant terms remain active. Twelfth, stochastic closures are needed when unresolved scales do not separate cleanly from resolved scales. Thirteenth, noisy Lorenz shows that deterministic and stochastic closures can both match data but differ in long-term invariant measure. Fourteenth, reduced Lorenz shows that learned stochastic closure can restore lost chaotic behavior. Fifteenth, EKI scaling depends on parallel forward solves, data-space matrix inversion, localization, and prior choices. Sixteenth, design and topology loops need closure models that are learned from available indirect evidence and checked against the behavior the decision actually uses.

The chapter's core idea: a closure is a promise about what the missing scales are doing. If you cannot observe that promise directly, infer it through the model outputs you can observe, but keep it sparse when data is limited and stochastic when unresolved dynamics behave like noise.
