Narrative chapter

Make The Physics Loss Fight Back

Read This Chapter As One Claim

Start with the promise of a PINN in the most ordinary words: make a neural network draw the solution to an equation, then punish it wherever the drawing breaks the equation. That sounds reasonable. The catch is that the punishment can be shaped so badly that training gets stuck even when the equation is right and the network is allowed to move. This chapter asks whether the physics loss should be changed from a passive score into an active challenger that searches for the mistakes.

Everyday problem The model is told the physics rule, but training still crawls or stalls, so the final surrogate may be wrong while looking disciplined.
Shared promise Let one network propose the PDE solution and another network hunt for residual errors, so the solver learns from a stronger opponent.
Hidden danger A smaller physics residual is not always a useful path to the right answer if the residual loss creates a stretched, badly conditioned landscape.
First rejection test If the method only looks good by epoch count, ignores extra work, or fails on rollout/design cases, the training claim is too weak.

This chapter uses video 68, Spencer Bryngelson's DDPS talk on competitive physics-informed networks. The talk is about a problem that has appeared several times in this course: adding a PDE residual to a neural-network loss sounds clean, but the training can still fail.

The first-principles question is this: if a PINN is failing because its residual loss creates a badly conditioned optimization problem, can we change the training game without changing the PDE we are trying to solve?

What A PINN Is Trying To Do

A physics-informed neural network represents the unknown solution of a differential equation with a neural network. Instead of training only on labeled data, it evaluates whether the network output satisfies the PDE and boundary conditions.

The appeal is clear. If we know the equation, we can generate a residual at many points without needing a measured truth value everywhere. Automatic differentiation gives the derivatives needed by the PDE residual.

network predicts solution
autodiff computes derivatives
PDE residual is measured
training reduces residual

The Old Idea Is Not The Same As A Solved Problem

The talk points out that physics-constrained neural networks are not a brand-new thought. Older work injected physical constraints, residual models, finite-element ideas, and physics-based preprocessing into neural networks decades before the PINN name became common.

The modern surge happened when better software, GPUs, autodiff, PyTorch, and TensorFlow made these ideas easy to try. That explains the popularity, but not the reliability. A method can become easy to run before it becomes easy to trust.

old physics constraints
modern autodiff tools
easy experiments
reliability still needs work

The Squared Residual Can Make Training Ill-Conditioned

The central diagnosis is about conditioning. In a simple linear PDE picture, minimizing a squared residual acts like solving normal equations. Normal equations can square the condition number of the original operator.

In everyday words, the training landscape becomes stretched and uneven. The optimizer may move easily in one direction and barely move in another. Even for a simple Poisson equation, the loss can refuse to fall quickly.

differential operator is hard
squared residual is formed
conditioning gets worse
optimizer struggles

The Fix Is A Minimax Residual Game

The competitive PINN changes the loss structure. The solution network still tries to make the PDE residual small. But a second network, called a discriminator in the talk, tries to find and amplify the places where the residual is wrong.

This creates a minimax game. One player tries to produce a good solution. The other player challenges it. The point is not competition for drama. The point is to avoid the damaging squared-residual structure while still solving the same PDE target.

solution network
residual challenger
back-and-forth training
same PDE target

Ordinary Gradient Descent Can Spiral

If two players compete, updating each one as if the other will stay still can fail. The talk uses a cat-and-mouse picture. If the mouse moves based on where the cat was, and the cat moves based on where the mouse was, they can chase around instead of settling.

That is why simultaneous gradient descent can diverge on simple games. It ignores the fact that the other player is also planning a move.

player sees old opponent move
updates alone
opponent reacts next
trajectory spirals away

Competitive Gradient Descent Lets Each Side Anticipate

Competitive gradient descent keeps cross-information. Each player updates while accounting for how the other player will respond. The talk describes this through cross-derivative terms and a Nash-equilibrium-style local update.

In plain words, the solution network and the challenger are no longer taking turns blindly. Each update asks, "If I move this way, how will the other side move?" That makes the training game better behaved.

solution move
challenger response
cross terms are kept
local equilibrium update

The Poisson Test Shows The Difference

On a smooth two-dimensional Poisson problem, the talk compares ordinary PINN training with the competitive version. The ordinary PINN barely reduces the relative error over many forward passes. The competitive PINN reaches much lower error.

The comparison counts forward passes instead of just epochs because the competitive method pays extra cost for Hessian-vector products. That is the right kind of honesty: a method should be judged by useful accuracy per real computational work, not by a flattering training counter.

same Poisson PDE
ordinary PINN stalls
C-PIN keeps improving
cost is counted fairly

Optimizer Tricks Are Not The Whole Answer

The talk compares against several optimizers and training variants. The message is not that Adam is bad and one magic optimizer is good. The deeper claim is that the loss formulation itself creates a conditioning problem.

Training tricks can help, but they do not necessarily address the reason the squared residual became hard. The competitive formulation changes the problem structure before optimizing it.

try better optimizer
some training improves

reformulate the game

Navier-Stokes Is Harder But Still Moves

The talk also tests a steady lid-driven cavity flow. The ordinary PINN barely trains, while the competitive PINN does show convergence, although noisier and slower than the simpler Poisson case.

This matters because many exciting claims about PINNs involve fluid dynamics. The result is not "Navier-Stokes is solved." It is more modest and more useful: the competitive framing can move a case where the standard PINN appears stuck.

lid-driven cavity

This Does Not Replace Ordinary Solvers For One Easy Solve

In the Q and A, the speaker is direct: if you only need one ordinary Poisson solve and have a good finite element or finite difference solver, use the traditional solver. It will likely be faster and more accurate.

The value of PINN-like methods is more plausible in many-query or high-dimensional settings. If the trained representation can answer many parameter cases, or if the dimension is high enough that grid methods become painful, the neural representation may become useful.

Expressivity Is A Separate Problem

The talk separates optimization from expressivity. Competitive training can help a badly conditioned optimization problem, but it does not prove that a chosen network is large enough or shaped correctly to represent every difficult solution.

Sharp fronts, rough coefficients, high frequencies, heterogeneous materials, and multiple PDE solutions can still create trouble. A better training game does not remove the need to understand the equation and the solution class.

optimization may improve
network still has limits
rough solutions are harder
math understanding remains needed

Why This Also Matters For Design

Design and topology optimization often need many PDE solves as geometry, material, or operating parameters change. If a PINN or C-PIN is trained across those parameters, it could become a reusable surrogate for repeated queries.

But this chapter also gives a warning for design: a physics-informed loss is not automatically reliable. If training fails because the loss is ill-conditioned, the design loop may optimize against a bad surrogate. Before using PINNs for design, test whether the residual formulation trains for the right reason and whether the network can express the needed solution features.

many PDE queries

The Chapter In One Chain

First, a PINN represents a PDE solution with a neural network. Second, automatic differentiation lets the loss include PDE derivatives without labeled truth data everywhere. Third, the usual squared residual can make training badly conditioned. Fourth, this can happen even for simple-looking PDEs. Fifth, C-PINs reformulate the residual as a minimax game between a solution network and a challenger network. Sixth, ordinary simultaneous gradient descent can spiral in such games because each player reacts to stale information. Seventh, competitive gradient descent keeps cross-response information so each player anticipates the other. Eighth, the Poisson tests show much stronger training than standard PINNs under fair cost counting. Ninth, Navier-Stokes examples show progress but also remaining difficulty. Tenth, C-PINs are not a replacement for a traditional solver on one easy PDE solve. Eleventh, they are more relevant for many-query and high-dimensional settings. Twelfth, design workflows should use them only after verifying training, expressivity, and transfer across the parameter range that matters.

The chapter's core idea: the physics loss can be the source of the training failure. Competitive PINNs make the residual fight back through a challenger network, turning a stuck least-squares problem into a better-conditioned game.

How To Test Whether You Understood This Chapter

Explain the failure without blaming the equation A PINN can know the right PDE and still train badly because the squared residual makes some directions easy to improve and other directions painfully slow. The issue can be the shape of the loss, not the physics law itself.
Explain the challenger in simple words The solution network says, "Here is my answer." The challenger network says, "Here is where your answer breaks the equation." Training becomes a game where the solver has to repair the mistakes the challenger exposes.
Separate training from representation Competitive training may help the optimizer move, but it does not prove the network can represent a sharp front, rough coefficient, high-frequency field, or multiple possible solutions. A better game is not the same as unlimited expressive power.
Connect this to topology and design For topology optimization, a neural PDE surrogate is useful only if it remains accurate while geometry, material, loads, and boundary conditions change. If the surrogate is stuck because the loss is ill-conditioned, the optimizer may design around a false physics response.
