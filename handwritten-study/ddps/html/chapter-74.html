Narrative chapter

Use Physics First, Then Let Learning Sharpen The Source

Read This Chapter As One Claim

Start with a hidden source inside a region and only wave measurements around the outside. The inside is not directly visible. If a neural network is given only a few outside curves and asked to draw the whole inside source, the job is badly shaped. This chapter uses physics first: turn exterior wave data into a rough interior source picture, then ask learning to clean that picture instead of guessing the interior from scratch.

Everyday problem We can measure waves outside a region, but the source, defect, obstacle, or internal activity we care about is hidden inside.
Shared promise Use the wave equation to build a rough source image, then use image-to-image learning to remove blur and artifacts.
Hidden danger Iterating the physics inversion too long can amplify noise, while a black-box direct learner faces a severe information mismatch.
First rejection test If the method only creates sharper-looking images but worsens measured error or fails on new source families, the reconstruction claim is too weak.

This chapter uses video 77, Ying Liang's DDPS talk on data-assisted algorithms for inverse random source scattering problems. The talk is about finding an unknown wave source inside a region using measurements taken outside the region, even when the source has randomness and the medium may be partly unknown.

The first-principles question is this: if all we can measure is a wave field on a surrounding boundary, how can we infer where the hidden source is without asking a neural network to guess the whole interior from boundary curves alone?

Inverse Problems Work Backward From Measurements

A direct problem starts with the physical properties and solves the PDE to predict measurements. An inverse problem starts with the measurements and tries to recover a hidden property, source, obstacle, or medium.

The hard part is that inverse problems can be nonunique, unstable, noisy, and computationally large. A small measurement error can cause a large reconstruction error if the backward map is not handled carefully.

direct solve predicts data
inverse solve recovers cause
noise can grow
need stabilizing structure

Scattering Means Waves Interact With A Source Or Medium

Scattering problems study how waves move through space and interact with sources, obstacles, interfaces, and media. The waves can be acoustic, electromagnetic, or elastic.

There are several inverse scattering tasks. Inverse medium problems recover the medium. Inverse obstacle problems recover an unknown object or interface. Inverse source problems recover the source that created the measured wave field.

wave travels
medium changes it
obstacle scatters it
source created it

Randomness Enters Because Real Sources Are Not Clean

The talk models the source as a deterministic average part plus a random white-noise-driven part. In everyday terms, the source has a mean behavior and a variability around that mean.

This matters because many real measurements contain unpredictable environmental noise, random source fluctuations, incomplete system knowledge, and fine-scale effects that are not cleanly modeled. The inverse problem therefore tries to recover statistics of the source, especially its average and variance.

mean source pattern
random fluctuation
many realizations
recover mean and variance

The PDE Is The Helmholtz Equation

The governing equation is a stochastic Helmholtz equation, a time-harmonic wave equation. The solution is the wave field. The wave number controls the wavelength. A medium coefficient changes how waves propagate. The source drives the field.

A radiation condition is added so outgoing waves behave correctly far away. Without that condition, the direct wave problem may not have the unique physical solution we want.

wave number
medium coefficient
random source
measured wave field

Known And Unknown Media Change The Difficulty

If the medium is homogeneous, the source reconstruction can use an integral equation based on the known fundamental solution. If the medium is inhomogeneous but known, the method is harder but still has structure. If the medium is inhomogeneous and unknown, the classical integral-equation route no longer applies cleanly.

This third case is where the data-assisted method becomes especially useful. The first-stage physics model may be imperfect, but it can still give a rough image that learning can improve.

homogeneous medium
known inhomogeneous medium
unknown medium
learning helps correction

The First Stage Uses Physics To Make A Rough Interior Image

In the homogeneous case, the wave solution can be written with an integral formula. Taking expectations and variances of the measured wave field leads to linear operator equations for the source mean and variance.

The method uses a regularized Kaczmarz iteration to solve those equations. Kaczmarz can be pictured as repeatedly projecting a current guess onto solution planes defined by different measurements or wave numbers.

boundary measurements
integral operator equations
few Kaczmarz steps
rough source image

Stopping Early Is A Feature, Not A Mistake

The talk explains why the first stage does not run forever. Iteration error decreases with more steps, but measurement noise can be amplified by more steps. After a point, continuing can make the reconstruction worse.

So the first stage is deliberately rough. It gives enough interior structure for the learning stage to work with, while avoiding excessive noise amplification.

more iterations reduce bias
noise also grows
stop after few steps
usable rough prior

The Second Stage Is Image To Image

Once the first stage produces a rough image, the problem changes. It is no longer boundary curve directly to interior source. It is rough interior image to sharper interior image.

That is a much better job for machine learning. The dimensions now match, and computer-vision tools can learn how rough Kaczmarz artifacts tend to relate to true source shapes in the training distribution.

image-to-image model

U-Net Preserves Location While Cleaning The Image

The U-Net version uses an encoder-decoder structure with skip connections. The encoder compresses the rough image into features. The decoder rebuilds the cleaned source image. Skip connections carry local image details forward so the output does not lose location information.

This matters because source reconstruction is spatial. The model must not merely say "three sources exist." It must place them in the right parts of the domain.

rough source image

Pix2Pix Tries To Make Sharper Images

The Pix2Pix model is a conditional generative adversarial network. The generator tries to turn the rough image into a realistic source image. The discriminator tries to tell generated image pairs from real training pairs.

The talk notes an interesting tradeoff. Pix2Pix can give sharper-looking boundaries, even when its numerical error is not always lower than U-Net's. That means visual sharpness and measured relative error are related but not identical.

sharper edges
error still must be measured

Why Not Learn Boundary Data To Source Directly?

The Q&A makes this point explicit. If we remove the physics first stage, the network receives a few boundary curves and must produce a full two-dimensional source image. That is a severe dimension and information mismatch.

The physics first stage converts boundary data into a rough interior image. That gives the network a much better starting point and keeps known wave physics in the pipeline.

boundary curves only
full interior image needed
black box struggles
physics bridges dimensions

The Training Data Still Costs Real Work

The learned stage is fast at test time, but training data generation is expensive. For each sample, many random realizations may be needed to estimate the mean and variance of measured fields. Each realization requires a forward solve.

This is the same offline-online tradeoff seen in other chapters. Training can be costly, but once trained, the online reconstruction combines a small physics solve with a fast neural correction.

many random realizations
many forward solves
expensive offline data
fast online correction

Generalization Is Tested But Not Unlimited

The training examples use three circular inclusions, but the method is also tested on five inclusions and simple phantom-like ellipse shapes. The reconstructions remain useful, which suggests some generalization beyond the exact training shape count.

That does not mean the method can handle every source family automatically. It means the physics stage plus image correction carries enough structure to survive some changes. New source classes, noise levels, media, and geometries still need validation.

trained on one source family
tested on new shapes
useful transfer appears
validate new regimes

Obstacle Scattering Is The Next Harder Case

The future-work section moves from inverse source reconstruction to inverse obstacle reconstruction. That problem is nonlinear because the unknown is a shape that changes how waves scatter.

The same philosophy appears again: use a traditional probing method to get a rough obstacle image, then learn the mapping from rough reconstruction to exact shape. The early results show the approach is promising but not yet as clean.

unknown obstacle shape
nonlinear scattering
probing gives rough shape
learning improves it

Why This Matters For Design And Topology

Design and topology problems often involve hidden causes inferred from exterior responses: defect locations from waves, load locations from vibration, material damage from boundary sensors, or internal source regions from field measurements.

The design lesson is to avoid an all-or-nothing choice between classical inversion and black-box learning. Use physics to move from sparse exterior data to a rough physically meaningful interior representation. Then use learning to correct the systematic blur, artifacts, and missing sharpness.

The Chapter In One Chain

First, inverse scattering works backward from measured waves to hidden media, obstacles, or sources. Second, random source problems recover source statistics, especially mean and variance. Third, the stochastic Helmholtz equation connects wave number, medium, source, and measured field. Fourth, known homogeneous media allow a physics-based integral-equation reconstruction. Fifth, regularized Kaczmarz gives a rough image but becomes noise-sensitive if iterated too long. Sixth, unknown media make the classical route harder, but the rough physics image can still be useful. Seventh, the second stage learns rough image to exact image, which is easier than boundary curve to interior image. Eighth, U-Net preserves locations through skip connections. Ninth, Pix2Pix can sharpen edges through adversarial training. Tenth, training data costs many forward solves and random realizations. Eleventh, generalization exists but must be checked for new source families and media. Twelfth, the same rough-then-learn idea can extend toward obstacle scattering. Thirteenth, design and topology inverse problems should use physics to create the right representation before asking learning to correct it.

The chapter's core idea: learning works better when physics first changes the problem into the right shape. Boundary wave data is too indirect; a rough physics reconstruction gives the neural network an interior image it can actually improve.

How To Test Whether You Understood This Chapter

Explain scattering from zero A wave travels through a region and is changed by a source, medium, or obstacle. In inverse scattering, we measure the changed wave and work backward to infer what hidden thing caused it.
Explain why randomness matters The source is not treated as one perfectly clean pattern. It has an average part and a variable part, so the reconstruction asks for source statistics such as mean and variance.
Explain the two-stage method The first stage uses the Helmholtz physics and regularized Kaczmarz iteration to make a rough interior image. The second stage uses U-Net or Pix2Pix to turn that rough image into a cleaner source estimate.
Connect this to topology and design Design inspection often uses exterior sensors to infer hidden defects, loads, sources, or internal topology. The lesson is to use physics to create a meaningful interior representation before using learning to sharpen the decision evidence.
