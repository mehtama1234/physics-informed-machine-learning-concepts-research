Mathematical Concept Atlas

Deep Learning

scientists have many measured examples but no formula that predicts the next case

Physics-Informed Neural Networks

sparse measurements from experiments, but the answer must obey known physical laws like gravity or heat flow

Partial Differential Equations

a quantity changes over space and time, so one number is not enough to describe what's happening

Operator Learning

engineers need to predict all the fields (temperature, pressure, flow) across a space and time for many input cases, not just one

Scientific Machine Learning

predictions must obey the physical laws that define the problem, not just fit the data

Surrogate Modeling

running a full simulation is too expensive to do for every design choice or question

Uncertainty And Generalization

a prediction from a model is only useful if you know under which conditions you should actually trust it

Optimization For Learning

models need a way to measure progress so they know which settings are better or worse

Generative Modeling

some tasks need many plausible examples, not a single best prediction, to explore what's possible

Graphs And Geometric Learning

molecules, proteins, and meshes have a shape and connections that rows of numbers throw away

Neural Differential Equations

scientists watch a system change over time but don't know the rule driving that change

Symbolic Regression And Model Discovery

a scientist may need a readable equation, not a numerical model that predicts but cannot be understood

Foundation Models For PDEs

scientists train separate models for each PDE, each grid size, each parameter—expensive duplication

Attention For Scientific Fields

a local spot in a field may depend on faraway information, but scanning everywhere costs too much
