First-Principles Walkthrough

What this lecture is really about: How to learn solution operators for PDEs without breaking resolution independence

The question it answers: When we build neural networks to learn PDE solutions, why do they fail to generalize across different grid resolutions, and how can we design networks that work faithfully at any resolution?

Something concrete to hold onto: Imagine you learn to recognize a person's face from a photo at 100×100 pixels. Later, you get a 200×200 pixel version of the same person—are the pixel values at each location identical? No. So your network trained on specific pixel positions sees different inputs, even though it's the same underlying face. PDEs have the same problem: functions are the same, but sampled values differ with resolution.

The core problem starts with two worlds that never quite fit together: infinite-dimensional mathematics and finite-dimensional computers. PDEs live in infinite dimensions—a solution is a continuous function defined everywhere. But we compute on grids, which are finite samples. The key insight from signal processing (going back to Shannon and earlier) is that you can map perfectly between these worlds IF certain conditions hold. Band-limited functions—functions whose frequency content stops at some finite cutoff—can be exactly reconstructed from equally-spaced samples, provided you sample densely enough. Specifically, if the highest frequency in your function is ω, you need at least 2ω+1 grid points. This is the Nyquist barrier. As long as you stay above this barrier, discretization introduces zero error: the sampled values and the continuous function are completely equivalent.

Now let's see why standard convolutional neural networks (CNNs) fail. A CNN uses discrete convolutions: you slide a fixed-size kernel window over discrete grid points and compute outputs. This is perfectly fine if you always work with the exact same grid. But when you change the grid resolution, everything breaks. Here's the invisible failure: your kernel hits three specific grid points during training (say, at positions 0.0, 0.25, 0.5). During testing on a finer grid, it hits three new points at positions (0.0, 0.125, 0.25). Even though these functions are band-limited and represent the same underlying solution, the specific pixel values are different. The kernel doesn't 'know' it's seeing the same function—it only sees different numbers. These small differences compound through layers, and errors grow explosively. The network cannot generalize because the convolution operation is tied to the discrete grid itself, not the underlying continuous function.

Fourier Neural Operators (FNOs) tried a different approach: instead of convolving in physical space, apply Fourier transforms to switch to frequency space, do the convolution there, then transform back. At first glance this looks better. But FNOs reveal a hidden problem with pointwise nonlinearities. When you apply a nonlinearity like ReLU or squaring to a band-limited function, you create new frequencies that shouldn't exist. Mathematically, if you square a function with frequency components up to 10, you suddenly get components up to frequency 20. This happens because nonlinearities mix modes together—a property of how sine and cosine functions multiply. In FNOs, the Fourier coefficients are truncated to a fixed number of modes, but the nonlinearity breaks the band-limited assumption. After each activation, the output has higher frequency content, which gets aliased and corrupted when you truncate back down. The convolution tries to correct for this in the next layer, but it's fighting a losing battle. You get small errors that accumulate across layers.

To understand how to fix this, we need to think about what it really means to respect the mathematics. The approach of Representation Equivalent Neural Operators (ReNOs) formalizes the idea: learning and discretization should commute. Whether you first project to finite dimensions then learn, or learn then discretize, you should get the same result. This is only possible if the encoding (sampling) and reconstruction (interpolation) operations preserve the structure perfectly. For band-limited functions, sync interpolation does this: given sampled values on a grid, you can exactly reconstruct the continuous function using a special sinc basis, then resample it at any new grid resolution and get back the same values. The miracle of this is that it's not magic—it follows directly from Shannon sampling theory.

Convolutional operators implement this insight in physical space rather than Fourier space. The key move is subtle but elegant: use continuous convolutions on band-limited functions with a discrete kernel. This means your kernel is defined only at discrete points (say, three points), but your input and output are treated as continuous functions. When you want to apply the operator to data on a different grid, you don't apply the kernel directly to the new grid points. Instead, you first use sync interpolation to reconstruct the continuous function from the test-grid samples, then project it back down to your training resolution, apply the kernel there, and you get an answer that is mathematically guaranteed to be identical. This is the trick: you resize the input and output, not the kernel. The Nyquist condition ensures that the interpolation and downsampling lose no information, so you're really operating on the same underlying function.

The nonlinearity problem requires a completely different solution. You cannot apply a pointwise nonlinearity and remain representation-equivalent, because pointwise operations introduce frequencies in an uncontrolled way. Instead, use upsampling-then-nonlinearity-then-downsampling. The idea is to deliberately expand the bandwidth before applying the nonlinearity, creating space for the higher frequencies that will be generated. If your function has 10 frequency components, you artificially expand the representation to allow 20 components (padding the extra ones with zeros), then apply the nonlinearity on this expanded grid where there are enough sample points. After the nonlinearity generates its higher frequencies, you downsample back to your original 10-component space using sync-based filtering. This kills the high frequencies that don't belong. For polynomial nonlinearities, you can prove this is exact if the expanded bandwidth is large enough. ReLU and smooth activations still leave small residual artifacts, but the error is dramatically reduced compared to pointwise nonlinearities without expansion.

The deeper insight here is that the activation is no longer pointwise—it becomes nonlocal. By upsampling and downsampling, you're multiplying with filters and truncating frequency content, which couples information across space. This nonlocal structure is actually the key to making the architecture work. You're not just applying a function at each point; you're actively managing the frequency content of the entire field. This is how a neural operator can learn to be truly resolution-independent: the convolutions preserve band-limited structure by working continuously, and the nonlinearities accommodate the inevitable frequency growth by expanding and contracting the bandwidth in a controlled, mathematically justified way. The result is an architecture that can be trained on one resolution and tested faithfully on any other resolution satisfying the Nyquist barrier.

Key ideas in plain words

  • Band-limited functions (functions with a finite frequency cutoff) can be perfectly represented by discrete samples if the Nyquist barrier is satisfied—this means the gap between samples is small enough that no information is lost going from continuous to discrete and back.
  • Standard CNNs fail at resolution generalization because they apply fixed-size kernels to discrete grid points, making the network resolution-dependent—on a finer grid, the kernel hits different point values even for the same underlying function.
  • Pointwise nonlinearities (like ReLU applied to each grid point) create high frequencies that shouldn't exist in band-limited functions, corrupting the representation unless bandwidth is artificially expanded to accommodate them.
  • Representation equivalence means learning and discretization should commute—the architecture must ensure that projecting to finite dimensions, learning, and reconstructing up gives the same result as learning in infinite dimensions then discretizing.
  • Continuous convolutions with discrete kernels, combined with sync-based interpolation and resampling, allow the convolution operation to work on the underlying continuous function rather than the discrete grid.
  • Upsampling-nonlinearity-downsampling makes the activation function nonlocal and frequency-aware, deliberately expanding bandwidth before nonlinear operations then contracting back, which controls aliasing errors.
  • Practical implementation resizes test inputs back to the training resolution before applying the operator, using sync interpolation as the bridge between resolutions—this is not magical but a direct consequence of band-limited function theory.

Worked intuition: Suppose you have a smooth temperature field represented on a 16-point grid. Training goes fine. At test time, you get a 32-point grid (finer resolution) of the same physical phenomenon. With a standard CNN: the kernel sees 3 points at positions (0.0, 0.5, 1.0) during training—it learns to map those specific values. On the finer grid, the same physical points are at (0.0, 0.25, 0.5, 0.75, 1.0)—the kernel now hits different values, so it fails. With a convolutional operator: you take the 32-point values, use sync interpolation to lift them to a continuous function (band-limited to 16 frequencies because 32 points satisfy Nyquist for that band), then downsample them back to 16 points using the same interpolation. You now have values that represent the same continuous function on the original 16-point grid. The kernel applies, and you get a result that perfectly generalizes. The nonlinearity sits between upsample and downsample steps: if the intermediate output has 16 frequencies, you upsampled to 32, apply ReLU pointwise (which creates frequencies up to 32), then downsample back to 16, effectively filtering out the spurious high frequencies while keeping the physically meaningful ones.

Where it breaks down: The theory assumes band-limited functions—if your PDE produces sharp discontinuities or high-frequency oscillations beyond your discretization, the method breaks. The Nyquist barrier must be respected; if you try a coarser grid than Nyquist allows, all bets are off. In practice, PDEs often have solutions that are not perfectly band-limited; the band limit must be large enough to capture all physically relevant scales. The upsampling factor in the nonlinearity is a design choice; doubling the bandwidth works well empirically but requires computational overhead—you cannot expand infinitely. For nonpolynomial nonlinearities like ReLU, residual high-frequency artifacts remain even after downsampling; the method is approximate, not exact, though the error is much smaller than pointwise approaches. On intricate, irregular geometries (not regular grids), the theory becomes harder to implement because resampling and interpolation are no longer straightforward.

Takeaway: Neural operators work across resolutions when you treat the underlying continuous functions and frequency content seriously, not the discrete grid points: use continuous convolutions with data resampling, expand bandwidth deliberately before nonlinearities to control aliasing, and rely on sync-based interpolation to bridge between representations—this architecture lets you train once and generalize to any resolution that satisfies the Nyquist condition.
