First-Principles Walkthrough

What this lecture is really about: Attention as a learned, data-dependent kernel for scientific fields

The question it answers: How can we use Transformers (which were designed for language) to learn operators that map scientific fields to other fields, and how do we make them computationally feasible when your data lives on a high-resolution grid?

Something concrete to hold onto: Imagine you're trying to predict the temperature at one point in a room. You could look at all other points and decide which ones matter most—nearby points matter more, far ones less. Attention does exactly this, but lets the machine *learn* which points matter, and learns it differently depending on the data it sees. Most other approaches bake in a fixed rule (like "nearby is important"), but attention figures it out from scratch.

At its heart, a Transformer is a stack of blocks that look at relationships between different parts of your input. The key piece is *attention*, which is a way to compute "which other parts of my input should I focus on when computing the output at this location?" You have input points (let's call them tokens—think of them as grid points in your domain), and for each token you ask: what weighted combination of all the other tokens should I use? The weight for each other token is computed by a softmax, which just means: how important is this other token, as a probability that sums to 1. The clever part is that these weights are learned—they're not hard-coded. If your data has a lot of local structure, the network will learn to give high weight to nearby points and low weight to distant ones. But if your problem needs global information, the network can learn that too.

Here's why this is different from other operator learners like CNNs or Fourier Neural Operators. A CNN uses a *fixed kernel*—you decide in advance that a point depends only on its 3×3 neighbors, and this kernel is the same everywhere and doesn't change based on the data. Fourier Neural Operators learn a kernel in Fourier space, but again it's fixed once trained. Attention builds a *data-dependent kernel*. Every point can in principle attend to every other point, and the strength of that attention is learned from the data. This is wildly more flexible, but it comes at a cost: you have to compute attention weights between all pairs of points, which is *quadratic* in the number of points.

Let's make that cost concrete. Imagine a simple incompressible fluid in 2D. At each grid point you have 2 values (the x and y components of velocity). If your domain is 128 × 128, that's 2^14 grid points. The attention calculation scales as (2^14)^2 = 2^28 operations—that's roughly a billion. Now move to 3D at the same resolution: 128^3 = 2^21 points, so 2^42 operations—trillions. Your computer can't handle this. And you're doing this not just once at inference (when you use the trained model), but thousands of times during training, looping over your entire dataset.

The solution for images is *patching*. Instead of treating each pixel as a token, you group nearby pixels into patches—say 16×16. A 128×128 image becomes just 64 tokens (one per patch). You learn a small neural network that extracts features from each patch—a weighted average with learnable weights—and feeds these 64 learned summaries into the Transformer. Now the quadratic cost is on 64 tokens instead of 2^14, which is 4096 instead of 268 million operations. The trade-off: you lose fine-grained information when you average pixels into a patch. The fix: you learn additional feature channels (like you increase from 2 to 20 dimensions) so the network can recover detail.

But here's the rub for scientific fields: if you're predicting temperature or stress at each point, a 16×16 patch loses too much. You might need 4×4 or 8×8 patches to capture the physics. A 4×4 patch multiplies the number of tokens by 16, which multiplies the quadratic cost by 256—suddenly you're back to infeasibility. The paper introduces *windowed attention* to solve this. Instead of computing attention across all patches, you divide your domain into larger windows (say, 4×4 windows, each containing 4×4 patches). Inside each window, patches attend only to each other—like a CNN's receptive field. This cuts the quadratic cost dramatically: if you have 20 windows instead of 256 patches, 20^2 = 400 operations instead of 256^2 = 65,536.

The remaining trick is that you *shift* the windows across layers. In layer 1, your window partitions the domain one way. In layer 2, you shift the partition—so a pair of patches that were in different windows in layer 1 are now in the same window. By alternating the window positions, information slowly propagates globally. After a few layers, even patches that were far apart initially have been brought into the same attention window, so they influence each other. It's like a CNN's receptive field growing with depth, but done via discrete shifts instead of strides.

To wrap up: attention is a learned, fully data-driven way to decide which parts of your input contribute to the output at each location. This is effective—it can discover both local and global structure—but expensive. For scientific fields on grids, you patch to compress tokens, then use windowed attention to avoid the full quadratic cost. You trade off some information loss (from patching) for computational feasibility, but you recover it by learning richer features in the compressed patches. The key intuition is that attention without constraints is too expensive, so you impose structure (patches, windows, shifts) that respects the regularity of physical fields—things change slowly locally, but accumulate change over large distances.

Key ideas in plain words

  • Attention is a learned kernel (not fixed like CNNs): each point learns to weight all others based on the data, so it can discover whether locality, global reach, or a hybrid is important.
  • Quadratic cost: Attention requires comparing every pair of tokens, which scales as (number of tokens)^2—OK for text (thousands of tokens), infeasible for grids (millions+).
  • Patching: Group grid points into patches, extract learned features per patch (weighted averages), reducing tokens from millions to thousands, quadratic cost from trillions to millions.
  • Windowed attention: Compute attention only within local windows, not globally; shift windows across layers so distant patches eventually interact, keeping cost linear or log-linear.
  • Information loss vs. computation: Patching loses detail, but you recover it by learning more feature channels per patch—trading spatial resolution for channel depth.
  • Data-dependent inductive bias: Unlike CNNs (which bake in locality) or FNOs (fixed Fourier kernel), attention learns its inductive biases from data, so it can adapt to different physics.

Worked intuition: Consider predicting velocity in a 2D fluid from pressure. Without any structure, pure attention on a 128×128 grid is infeasible (2^28 ops). You patch to 64 patches (cost now ~4000 ops). But 16×16 patches might smear out shear flows at the boundaries. You shrink to 8×8 patches (256 tokens, ~65k ops)—still expensive but doable. Now you add windowed attention: group 256 patches into 16 windows of 16 patches each. In layer 1, each window attends internally (16^2 = 256 ops per window, 16 windows total = 4k ops). In layer 2, shift the windows so different pairs overlap. After 4–5 layers of shifted windows, any two original patches have been co-attended. The model learns that nearby patches contribute strongly (via high attention weights) and distant ones weakly (learned by the network), so it approximates locality without hard-coding it. The network also discovers if there are long-range correlations (e.g., a faraway pressure anomaly that triggers flow at your point) because after shifting, all pairs eventually interact.

Where it breaks down: Windowed attention loses global information within a single layer—you can't see across the domain at once. If your physics has strong long-range correlations (e.g., a shock wave that couples distant regions instantly), you need many layers of window-shifts to propagate information, which increases depth and training time. Patching itself loses high-frequency detail; if your problem has sharp gradients or thin boundary layers, a 4×4 or 8×8 patch is still coarse. The network tries to recover this via learned feature channels, but there's a hard limit: if the patch size is too large, you can't reconstruct sub-patch variation. Also, the approach assumes your domain is regular and patched regularly—it's less natural for unstructured meshes or irregular geometries. Finally, window shifts are discrete; information propagation is slow compared to global attention, so you need deep networks.

Takeaway: Attention learns which parts of your input matter for the output, without hard-coding locality—effective but expensive on grids. Patching + windowed attention + shifts make it feasible: you compress the grid into tokens, attend locally to keep cost down, and shift windows across layers so information gradually propagates globally. The trade-off is simplicity for expressiveness, and you pay with depth and training time. It's a data-driven way to discover the right balance between local and global structure, which is why it works well when you don't know the physics a priori.
