Purpose

Show how source text becomes concepts, themes, evidence, and pages.

Process

  1. Load playlist records, metadata paths, captions, and cleaned transcript text.
  2. Match concept keywords against title and transcript text.
  3. Build concept, theme, evidence, domain, decision, glossary, and learning-path data.
  4. Write JSON analysis files before rendering the HTML site.
