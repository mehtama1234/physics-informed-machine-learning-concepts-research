Surrogate Modeling

A surrogate is a faster stand-in for a slower trusted process.

Domain Story

If every wing-shape test takes hours, a checked stand-in can screen many shapes before the expensive solver is used again.

Problem

a trusted simulator may be too slow to run for every design, control, or uncertainty question

Start With What Is Observed

expensive solver inputs and outputs for a limited set of cases

Name What Is Hidden

the solver answer for every new query someone wants to ask

Build The Mathematical Shape

1. Name the expensive source of truth.
2. Name the inputs people will vary.
3. Name the output quantity needed for decisions.
4. Fit the cheap stand-in on trusted examples.
5. Measure error near the edge of intended use.

Plain Formula

new query -> fast stand-in -> approximate answer with a stated use range

Why This Matters

Speed changes what questions scientists and engineers can afford to ask.

Failure Test

compare against the full solver on new cases near the edge of the intended use

Red Flags

  • The surrogate is described without its use range.
  • The edge cases are not tested.
  • The output metric ignores the decision people actually make.
  • The full solver is never used again for spot checks.
