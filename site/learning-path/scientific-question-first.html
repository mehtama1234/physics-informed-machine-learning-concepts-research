Start With The Scientific Question

Question

What is being predicted, explained, designed, or checked?

Why This Comes Here

Physics-informed machine learning is not one trick. The method depends on the scientific job, the evidence in hand, and the changed case where a wrong answer would matter.

Plain Goal

Name the quantity, the domain, the evidence, and the changed case before naming a method.

No-Jargon Explanation

This step asks the reader to slow down before reaching for a method name. World: a scientist needs an answer for a real quantity. Evidence: measurements, equations, simulations, or old cases give partial support. Missing piece: the quantity needed for the next case is not directly known. The point is to make the missing piece visible before choosing any model. Mathematical move: choose the smallest learning route that carries the needed evidence. That move is only useful if it survives the stated rejection test. Reject it when: a changed case breaks the quantity the scientist actually needs. If a reader cannot say this in ordinary language, they are not ready to trust the technical page that follows.
