No-Jargon Concept Guide

Translate The Label Into A Job

Use this page when a concept name sounds familiar but the reason for it is still unclear. The label is not the explanation. The explanation starts when the reader can say the everyday problem, the evidence in hand, the hidden answer, the move being made, and the changed case that can reject the claim.

Concepts Without Hiding Behind Names

Deep Learning scientists often have examples of behavior but no short rule that predicts the next case many input-output examples from experiments, simulations, or measurements the exact rule that connects the input to the output adjust many weights until the model maps familiar inputs to the right outputs hold out a changed material, geometry, parameter range, or sensor condition
Physics-Informed Neural Networks measurements may be sparse, but the answer must still respect a known physical equation some measured values, boundary values, starting values, and a known differential equation the full field value at every point in space and time fit a neural network while also measuring how badly its output violates the known equation move the training points, inspect sharp regions, and compare against a numerical solve or held-out measurements
Partial Differential Equations a quantity changes over space and time, so one number is not enough to describe the situation a field such as temperature, pressure, concentration, velocity, or displacement how every point in the field affects nearby points over time write a local change rule that uses rates across space and time change the boundary, grid, source term, or physical scale and check conservation, stability, and measured error
Operator Learning one simulation answer is not enough when engineers need the whole map from inputs to solution fields many example inputs and their full solution fields the rule that maps a new input field to its new solution field learn the map from problem input to solution, not only one solution at a time change resolution, coefficients, boundary conditions, or forcing and check whether the predicted field still satisfies the scientific quantity being claimed
Scientific Machine Learning scientific work needs predictions that respect measurements, equations, uncertainty, and domain limits at the same time data, equations, units, simulation outputs, and domain limits which parts of the scientific system are missing, noisy, or too costly to compute directly combine learned prediction with scientific checks that name what the claim is allowed to mean state the scientific quantity first, then test it under a changed case that matters in that domain
Surrogate Modeling a trusted simulator may be too slow to run for every design, control, or uncertainty question expensive solver inputs and outputs for a limited set of cases the solver answer for every new query someone wants to ask train a cheaper stand-in for the expensive input-output behavior compare against the full solver on new cases near the edge of the intended use
Uncertainty And Generalization a prediction is not enough unless the user knows when it should be believed training cases, validation cases, prediction errors, and known shifts between cases how wrong the model may be on a case unlike the ones it learned from separate fit on familiar examples from evidence on changed examples move one important condition outside the training range and measure the first failure
Optimization For Learning learning needs a way to decide which model settings are better or worse a written score that says which model behavior is better or worse whether that score matches the scientific behavior the user actually cares about change model settings to lower the written score inspect what the score ignores, then check whether the ignored behavior fails after training
Generative Modeling some tasks need many possible examples, not one predicted answer examples of fields, molecules, flows, shapes, or other scientific objects the spread of possible valid objects beyond the examples learn how to sample new candidates that resemble the training family measure constraints, rare cases, conservation, and downstream task performance on generated samples
Graphs And Geometric Learning many scientific objects are not simple rows of numbers; their connections matter objects with parts and connections, such as meshes, molecules, or interacting components which neighboring and long-range interactions control the scientific quantity let information move along the object connections instead of flattening the object into a plain row change the mesh, rotate or move the object, or add missing interactions and inspect what breaks
Neural Differential Equations scientists may know that a system changes continuously but not know the exact rule for that change measurements of a system changing over time the rate rule that moves the present value into the future learn the missing rate rule and place it inside a time-evolution calculation run longer than the training window and check whether small rate errors accumulate into drift
Symbolic Regression And Model Discovery a scientist may need a readable equation, not only a model that predicts well measured variables and candidate mathematical ingredients which short formula, if any, actually explains the measured change search for a readable equation that fits the data and survives a changed case remove a needed variable, add noise, or test a new experiment and see whether the formula still predicts
Foundation Models For PDEs one trained model may be asked to handle many related equations, grids, parameters, or physical settings many PDE problem instances across equations, grids, parameters, or physical settings which shared structure carries from one scientific task to another train one broad model to reuse structure across many related field-prediction tasks hold out a new equation family, boundary type, scale, or rare regime and compare against a trusted solver
Attention For Scientific Fields a local patch of a field may depend on faraway information, but looking everywhere can be expensive large fields where one location may depend on other locations which distant parts matter for the local prediction let the model choose which parts of the field exchange information change the window size, inspect long-range effects, and compare behavior near boundaries or sharp structures

How To Read A Method Name

  1. Pause before treating the label as understanding.
  2. Say what the scientist or engineer needs to decide.
  3. Say what evidence is already present.
  4. Say what answer is still missing.
  5. Say what changes first when the claim becomes too broad.

Reader Test

A reader understands a concept label only when they can replace it with an everyday sentence about the job it does. That sentence must name evidence, hidden answer, field use, shape or topology if it matters, and the first changed case.
