Data-Only vs Physics-Informed Learning

Shared Problem

Both try to turn examples into predictions.

Data-only learning

Use this side when examples are abundant, the use range is narrow, and there is no trusted rule to add.

Physics-informed learning

Use this side when a known equation, boundary condition, conservation law, unit, or symmetry should constrain the answer.

Key Difference

Data-only learning listens to examples. Physics-informed learning also listens to rules about what answers are allowed.

How To Decide From First Principles

Do not start by asking which side sounds more impressive. Start by asking what shortage creates the problem. The shared problem is: Both try to turn examples into predictions. The shortage that creates the choice is: The shortage is whether examples alone carry enough evidence. When examples are thin between measurements, a trusted rule may carry information the data do not.

Use Data-only learning when examples are abundant, the use range is narrow, and there is no trusted rule to add. In plain terms, this side is chosen when its evidence matches the job and its failure boundary can be tested. The concrete version is: A measured property has many examples and no trusted equation for the target. Use data-only learning with a clear held-out test.

Use Physics-informed learning when a known equation, boundary condition, conservation law, unit, or symmetry should constrain the answer. In plain terms, this side is chosen when the scientific task asks for the kind of shortcut, rule, or evidence this side actually provides. The concrete version is: A temperature field has sparse measurements and a trusted heat equation. Add the physical rule so unsensed places are checked.

The dangerous middle is the wrong-choice case: Adding a physical rule that is incomplete or wrong for the experiment, or ignoring a trusted rule when data are sparse. This is where a shallow writeup usually fails. It names a method but does not name the quantity, use range, or changed case. The evidence that exposes the mistake is: Compare changed cases where the rule matters: boundaries, conservation, units, symmetry, or regions between measurements.

Decision Checklist

  1. Name the real quantity the scientist will use.
  2. Name the evidence each side is allowed to use.
  3. Name the repeated use case, single case, or changed case.
  4. Name the first failure that would make the choice wrong.
  5. Choose the side whose burden matches the job, not the side with the more impressive label.

Swap Test

Swap the choice deliberately. If choosing the other side would break the named scientific quantity, use range, or changed-case test, the difference is real. If both sides still sound interchangeable, the problem has not been stated clearly enough.
