Many Examples, No Clear Rule

Situation

You have many examples, but no trusted equation or readable law yet.

Best Starting Point

Deep learning

Why This Fits

The first useful move is to learn a flexible predictor, then test whether it carries the quantity that matters.

Use If

  • examples are plentiful
  • the measurement process is named
  • a held-out changed case can be built

Avoid If

  • the new setting differs from the examples
  • the target quantity is vague
  • a scientific rule is claimed without a rule check

Evidence Needed

held-out examples, changed measurement tests, target-quantity error, and a named first failure
