Need Many Valid Possibilities

Situation

The task needs many candidate fields, molecules, designs, or futures rather than one answer.

Best Starting Point

Generative modeling

Why This Fits

The useful product is a set of possible scientific objects that still obey the rules that matter.

Decision Burden From First Principles

A method choice is justified only when the shortage, evidence, hidden need, mathematical move, and rejection test line up. This table states what the choice has to carry before the starting point is defensible.

Shortagesome tasks need many possible examples, not one predicted answer
Observed Evidenceexamples of fields, molecules, flows, shapes, or other scientific objects
Hidden Needthe spread of possible valid objects beyond the examples
Why This Starting Point Earns Its Placelearn how to sample new candidates that resemble the training family
What The Choice Carriesa generated object must still pass physics and usefulness checks
First Rejection Testmeasure constraints, rare cases, conservation, and downstream task performance on generated samples

Choice Must Fail If

Reject this starting point if the situation cannot provide the observed evidence, if the hidden need is not the quantity the decision uses, or if the first rejection test cannot be run.

Use If

  • many plausible candidates are useful
  • validity checks can be stated
  • downstream use can reject bad samples

Avoid If

  • samples are judged only by appearance
  • constraints are not checked
  • rare but important cases are missing

Evidence Needed

constraint checks, rare-event checks, downstream-task tests, and examples of rejected samples
