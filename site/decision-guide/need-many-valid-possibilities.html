Need Many Valid Possibilities

Situation

The task needs many candidate fields, molecules, designs, or futures rather than one answer.

Best Starting Point

Generative modeling

Why This Fits

The useful product is a set of possible scientific objects that still obey the rules that matter.

Use If

  • many plausible candidates are useful
  • validity checks can be stated
  • downstream use can reject bad samples

Avoid If

  • samples are judged only by appearance
  • constraints are not checked
  • rare but important cases are missing

Evidence Needed

constraint checks, rare-event checks, downstream-task tests, and examples of rejected samples
