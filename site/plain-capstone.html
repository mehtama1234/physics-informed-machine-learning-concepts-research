Plain Capstone

Final Proof Of Understanding

This is the final learner-facing route through the course. A learner passes only when they can explain a topic from everyday need to bounded claim, then transfer the same idea through shape, topology, and field use.

Capstone Answer Template

  1. A person needs an answer because an everyday scientific shortage appears.
  2. The evidence in hand is named before the method.
  3. The hidden answer is named before the formula.
  4. The first-principles move says how evidence can carry the missing answer.
  5. The shape or topology check names what relation must not be lost.
  6. The field transfer names how the same idea appears in engineering, materials or biology, and climate or fields.
  7. The final sentence names the changed case that can narrow the claim.

Topic Capstone Prompts

Deep Learning

Final Answer Prompt: Explain why this topic matters without starting from its name.

  1. Start with the everyday need: lots of real examples but no equation to predict what comes next.
  2. Name the evidence: many input-output examples from experiments, simulations, or measurements.
  3. Name the missing answer: the exact rule that connects the input to the output.
  4. Name the first-principles move: adjust many weights until the model maps familiar inputs to the right outputs.
  5. Name the topology or shape check: Hold out a new shape family, camera view, mesh order, or scale and measure the target error.
  6. Name one engineering use: Sort old test runs so a designer can screen the next part before a costly build.
  7. Name one materials, chemistry, or biology use: Read images, spectra, molecules, or cell measurements when hand rules are incomplete.
  8. Name one climate, fluids, or field use: Learn repeated field patterns from stored simulations or measurements.
  9. End with the rejection test: hold out a changed material, geometry, parameter range, or sensor condition.

Physics-Informed Neural Networks

Final Answer Prompt: Explain why this topic matters without starting from its name.

  1. Start with the everyday need: sparse measurements, but the answer must follow known physical laws.
  2. Name the evidence: some measured values, boundary values, starting values, and a known differential equation.
  3. Name the missing answer: the full field value at every point in space and time.
  4. Name the first-principles move: fit a neural network while also measuring how badly its output violates the known equation.
  5. Name the topology or shape check: Move sensors, change the boundary, or bend the domain and compare the hidden field with trusted values.
  6. Name one engineering use: Estimate heat, stress, flow, or pressure when tests are sparse but the physical law is known.
  7. Name one materials, chemistry, or biology use: Fill in missing concentration, strain, or reaction fields while keeping known balance rules visible.
  8. Name one climate, fluids, or field use: Recover a full field from sparse measurements without ignoring the governing equation.
  9. End with the rejection test: move the training points, inspect sharp regions, and compare against a numerical solve or held-out measurements.

Partial Differential Equations

Final Answer Prompt: Explain why this topic matters without starting from its name.

  1. Start with the everyday need: something changes everywhere at once—how do you describe that with math?.
  2. Name the evidence: a field such as temperature, pressure, concentration, velocity, or displacement.
  3. Name the missing answer: how every point in the field affects nearby points over time.
  4. Name the first-principles move: write a local change rule that uses rates across space and time.
  5. Name the topology or shape check: Change the boundary, cut a hole, refine the mesh, or bend the region and check conservation.
  6. Name one engineering use: Write the rule for heat, stress, flow, pressure, or waves before choosing a learning method.
  7. Name one materials, chemistry, or biology use: Track diffusion, reaction, strain, growth, or transport through a material or tissue.
  8. Name one climate, fluids, or field use: Describe wind, heat, concentration, pressure, and water over space and time.
  9. End with the rejection test: change the boundary, grid, source term, or physical scale and check conservation, stability, and measured error.

Operator Learning

Final Answer Prompt: Explain why this topic matters without starting from its name.

  1. Start with the everyday need: predict all values (temperature, pressure, flow) across a whole space at all times, for several starting conditions.
  2. Name the evidence: many example inputs and their full solution fields.
  3. Name the missing answer: the rule that maps a new input field to its new solution field.
  4. Name the first-principles move: learn the map from problem input to solution, not only one solution at a time.
  5. Name the topology or shape check: Hold out a new geometry class, mesh resolution, boundary type, or coefficient range.
  6. Name one engineering use: Give fast field estimates for repeated wing, device, part, or load queries.
  7. Name one materials, chemistry, or biology use: Map a material setting, molecular field, or tissue condition to a response field.
  8. Name one climate, fluids, or field use: Map forcing, boundary, or initial fields to future solution fields.
  9. End with the rejection test: change resolution, coefficients, boundary conditions, or forcing and check whether the predicted field still satisfies the scientific quantity being claimed.

Scientific Machine Learning

Final Answer Prompt: Explain why this topic matters without starting from its name.

  1. Start with the everyday need: teach a program both the data and the physics rules so it predicts correctly on cases it never saw.
  2. Name the evidence: data, equations, units, simulation outputs, and domain limits.
  3. Name the missing answer: which parts of the scientific system are missing, noisy, or too costly to compute directly.
  4. Name the first-principles move: combine learned prediction with scientific checks that name what the claim is allowed to mean.
  5. Name the topology or shape check: Change shape, mesh, boundary, or sensor layout and inspect the scientific quantity.
  6. Name one engineering use: Use data and scientific checks together when a design decision has a cost.
  7. Name one materials, chemistry, or biology use: Tie learned predictions to units, mechanisms, measurements, and domain limits.
  8. Name one climate, fluids, or field use: Use learned models only with clear field checks, physical checks, and use ranges.
  9. End with the rejection test: state the scientific quantity first, then test it under a changed case that matters in that domain.

Surrogate Modeling

Final Answer Prompt: Explain why this topic matters without starting from its name.

  1. Start with the everyday need: running the real simulator costs too much money or time to do hundreds of times.
  2. Name the evidence: expensive solver inputs and outputs for a limited set of cases.
  3. Name the missing answer: the solver answer for every new query someone wants to ask.
  4. Name the first-principles move: train a cheaper stand-in for the expensive input-output behavior.
  5. Name the topology or shape check: Change holes, edges, mesh detail, or shape class and compare with the full solver.
  6. Name one engineering use: Screen many candidate parts, wings, devices, or loads before running the costly solve.
  7. Name one materials, chemistry, or biology use: Use a cheaper stand-in for repeated material, molecule, or tissue simulations.
  8. Name one climate, fluids, or field use: Answer repeated field queries faster than running a full model each time.
  9. End with the rejection test: compare against the full solver on new cases near the edge of the intended use.

Uncertainty And Generalization

Final Answer Prompt: Explain why this topic matters without starting from its name.

  1. Start with the everyday need: how do you know when a prediction is trustworthy instead of a blind guess?.
  2. Name the evidence: training cases, validation cases, prediction errors, and known shifts between cases.
  3. Name the missing answer: how wrong the model may be on a case unlike the ones it learned from.
  4. Name the first-principles move: separate fit on familiar examples from evidence on changed examples.
  5. Name the topology or shape check: Hold out a new shape family, missing connection, or mesh resolution and measure the error.
  6. Name one engineering use: Attach a use range and warning boundary to a prediction before a design choice.
  7. Name one materials, chemistry, or biology use: Say when a measured property prediction should weaken under a new lab or sample condition.
  8. Name one climate, fluids, or field use: Separate ordinary test success from success under changed climate, flow, or boundary conditions.
  9. End with the rejection test: move one important condition outside the training range and measure the first failure.

Optimization For Learning

Final Answer Prompt: Explain why this topic matters without starting from its name.

  1. Start with the everyday need: the program has millions of dials to turn and needs a way to know which turns make it better or worse.
  2. Name the evidence: a written score that says which model behavior is better or worse.
  3. Name the missing answer: whether that score matches the scientific behavior the user actually cares about.
  4. Name the first-principles move: change model settings to lower the written score.
  5. Name the topology or shape check: Inspect whether the trained answer breaks after relabeling, mesh change, or boundary change.
  6. Name one engineering use: Train toward the quantity that drives the design, not only average error.
  7. Name one materials, chemistry, or biology use: Set the training score so it respects measured properties, units, and known checks.
  8. Name one climate, fluids, or field use: Balance field error, physical checks, and decision costs during training.
  9. End with the rejection test: inspect what the score ignores, then check whether the ignored behavior fails after training.

Generative Modeling

Final Answer Prompt: Explain why this topic matters without starting from its name.

  1. Start with the everyday need: need several possible solutions, not just one best guess, to explore what could work.
  2. Name the evidence: examples of fields, molecules, flows, shapes, or other scientific objects.
  3. Name the missing answer: the spread of possible valid objects beyond the examples.
  4. Name the first-principles move: learn how to sample new candidates that resemble the training family.
  5. Name the topology or shape check: Test connected parts, forbidden holes, mesh validity, and downstream use.
  6. Name one engineering use: Propose candidate parts, layouts, fields, or operating cases for later testing.
  7. Name one materials, chemistry, or biology use: Suggest molecules, structures, images, or samples that should still obey known rules.
  8. Name one climate, fluids, or field use: Sample possible fields for stress tests, rare cases, or downstream solvers.
  9. End with the rejection test: measure constraints, rare cases, conservation, and downstream task performance on generated samples.

  3. Name the missing answer: which neighboring and long-range interactions control the scientific quantity.
  4. Name the first-principles move: let information move along the object connections instead of flattening the object into a plain row.
  5. Name the topology or shape check: Relabel nodes, rotate the object, refine the mesh, or add a missing edge and inspect the target.
  6. Name one engineering use: Model meshes, parts, sensor networks, or connected components without flattening away contact.
  7. Name one materials, chemistry, or biology use: Represent atoms, bonds, cells, proteins, grains, or interaction networks as connected objects.
  8. Name one climate, fluids, or field use: Carry information over irregular grids, sensor networks, coastlines, or mesh fields.
  9. End with the rejection test: change the mesh, rotate or move the object, or add missing interactions and inspect what breaks.

  5. Name the topology or shape check: Change the starting state, shape, or connection pattern and run longer than the training window.
  6. Name one engineering use: Predict changing heat, motion, wear, control, or flow when the exact rate rule is unknown.
  7. Name one materials, chemistry, or biology use: Learn reaction, growth, motion, or change rules from measured time traces.
  8. Name one climate, fluids, or field use: Learn missing pieces of a time-update rule for fields.
  9. End with the rejection test: run longer than the training window and check whether small rate errors accumulate into drift.

  4. Name the first-principles move: let the model choose which parts of the field exchange information.
  5. Name the topology or shape check: Change window size, long-range links, boundary regions, or point order.
  6. Name one engineering use: Route information across a part, surface, or field where distant regions interact.
  7. Name one materials, chemistry, or biology use: Let distant atoms, cells, residues, or regions influence a local prediction.
  8. Name one climate, fluids, or field use: Route information across fields where one region can affect another.
  9. End with the rejection test: change the window size, inspect long-range effects, and compare behavior near boundaries or sharp structures.
