Foundation PDE Model Reader Check

Setup

One broad model is trained across many PDE tasks.

Questions

  1. What task families were included?
  2. What shared structure is the model expected to keep?
  3. What whole task family was held out?
  4. What trusted source checks the new task?
  5. What would show that scale did not create scientific coverage?

Strong Answer Should Say

The answer names included and held-out task families, the shared structure being claimed, and a trusted solver or measurement for checking. It rejects broad claims when new equations, boundaries, scales, or rare regimes were not tested.

Weak Answer Warning

A weak answer treats broad training size as proof of broad scientific trust.
