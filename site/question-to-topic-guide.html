Question To Topic Guide

Start With The Need

Use this page before choosing a method name. Say the ordinary scientific need first: what you can see, what you need next, and what would make the answer fail. Then open the first topic that carries that need.

The point is not to memorize labels. The point is to learn the route from a real shortage to a claim you can test. If the route cannot name the evidence, the missing quantity, and the first changed case, the explanation is not ready.

Everyday QuestionOpen This TopicWhy This Is The First StopWhat To Check Before Trusting It
I have many examples, but I do not have a short rule. Where do I start? Deep Learning scientists often have examples of behavior but no short rule that predicts the next case. The first move is to adjust many weights until the model maps familiar inputs to the right outputs. the model can fit familiar examples while failing on a new material, geometry, scale, or boundary condition
I have a few measurements and a known equation. How do I make them work together? Physics-Informed Neural Networks measurements may be sparse, but the answer must still respect a known physical equation. The first move is to fit a neural network while also measuring how badly its output violates the known equation. the equation penalty can look small while the solution is wrong in hard regions, sharp layers, or unseen boundary cases
My quantity changes across space and time. What language describes that change? Partial Differential Equations a quantity changes over space and time, so one number is not enough to describe the situation. The first move is to write a local change rule that uses rates across space and time. a learned shortcut can ignore boundary conditions or conservation behavior that the PDE was carrying
I need the whole answer field for new inputs, not only one solved case. What carries that map? Operator Learning one simulation answer is not enough when engineers need the whole map from inputs to solution fields. The first move is to learn the map from problem input to solution, not only one solution at a time. the learned map can give plausible-looking fields that violate the equation or fail on a shifted input family
I need data, equations, units, and checks to live in one scientific claim. What is the broad home for that? Scientific Machine Learning scientific work needs predictions that respect measurements, equations, uncertainty, and domain limits at the same time. The first move is to combine learned prediction with scientific checks that name what the claim is allowed to mean. the method becomes a generic fitting tool if the physical quantity, scientific claim, and validation case are not named
My trusted solver is too slow to run for every design or control question. What is the first shortcut to study? Surrogate Modeling a trusted simulator may be too slow to run for every design, control, or uncertainty question. The first move is to train a cheaper stand-in for the expensive input-output behavior. speed can hide missing physics when the surrogate is used beyond the regime where it was checked
I have a prediction, but I need to know when to believe it. What topic handles that? Uncertainty And Generalization a prediction is not enough unless the user knows when it should be believed. The first move is to separate fit on familiar examples from evidence on changed examples. training error can look good while the model fails under a new geometry, parameter range, sensor, or physical regime
The model is changing its settings. How do I know what it is being asked to improve? Optimization For Learning learning needs a way to decide which model settings are better or worse. The first move is to change model settings to lower the written score. a model can optimize the written score while missing the scientific behavior the score failed to name
I need several possible fields, molecules, shapes, or scenarios, not one answer. Where do I start? Generative Modeling some tasks need many possible examples, not one predicted answer. The first move is to learn how to sample new candidates that resemble the training family. generated samples can look realistic while breaking constraints, conservation, or rare-event behavior
My object has parts, neighbors, bonds, mesh points, or shape. Which topic keeps those relations visible? Graphs And Geometric Learning many scientific objects are not simple rows of numbers; their connections matter. The first move is to let information move along the object connections instead of flattening the object into a plain row. the graph can encode the wrong neighborhood, hide missing interactions, or fail when the mesh changes
A system changes over time, but the rate rule is partly unknown. What topic should I open? Neural Differential Equations scientists may know that a system changes continuously but not know the exact rule for that change. The first move is to learn the missing rate rule and place it inside a time-evolution calculation. small learned-rate errors can accumulate until long-time predictions drift away from the real system
I want a readable equation from measured variables. What topic is about that search? Symbolic Regression And Model Discovery a scientist may need a readable equation, not only a model that predicts well. The first move is to search for a readable equation that fits the data and survives a changed case. a neat formula can fit the training data while using the wrong variables or failing on a changed experiment
I want one field model to help across related PDE tasks. What should I read first? Foundation Models For PDEs one trained model may be asked to handle many related equations, grids, parameters, or physical settings. The first move is to train one broad model to reuse structure across many related field-prediction tasks. the model can look broad while missing rare regimes, new boundary conditions, or quantities not represented in training
Faraway parts of a field may affect the local answer. What topic explains that information route? Attention For Scientific Fields a local patch of a field may depend on faraway information, but looking everywhere can be expensive. The first move is to let the model choose which parts of the field exchange information. windowing or scaling choices can miss long-range effects that matter for the scientific quantity being predicted

If Your Question Mentions Shape

If the question mentions a mesh, molecule, graph, boundary, surface, hole, neighborhood, or connected part, slow down before flattening the object into a plain row. Ask what relation carries the scientific quantity. Then open the shape guide and the topic row above that names the same relation.

Reader Test

A reader understands the first-principles route when they can start with one everyday question, choose one topic, and say why that topic is the first stop without using the method name as the reason. The answer should name the evidence in hand, the hidden thing needed, the mathematical move, and the changed case that could reject the claim.
