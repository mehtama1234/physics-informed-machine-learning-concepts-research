Plain Formula Guide

This page translates the recurring formula shapes into everyday meaning. The goal is not to teach notation first. The goal is to show what information each formula carries, what it asks the model to do, and what test keeps the claim honest.

Concept Formula Shape Parts Everyday Reading What To Check Common Misread
Physics-Informed Neural Networks
topic · derivation		 total error = data error + equation error + boundary error
  • total error
  • data error
  • equation error
  • boundary error
 The equation gives the model a reason not to invent impossible behavior between data points. move the training points, inspect sharp regions, and compare against a numerical solve or held-out measurements Do not read the loss as proof that the learned field is physical. Read it as a list of promises that still need point placement, boundary checks, and held-out measurements.
Partial Differential Equations
topic · derivation		 change over time = movement through space + sources + boundary effects
  • change over time
  • movement through space
  • sources
  • boundary effects
 Most physics-informed machine learning borrows its scientific burden from PDEs. change the boundary, grid, source term, or physical scale and check conservation, stability, and measured error Do not read the equation as one more predictor. It is a statement about how change, space, sources, and boundaries must fit together.
Operator Learning
topic · derivation		 input field -> learned field-to-field map -> output field
  • input field
  • learned field-to-field map
  • output field
 It targets repeated simulation work, where the valuable object is the whole input-output map. change resolution, coefficients, boundary conditions, or forcing and check whether the predicted field still satisfies the scientific quantity being claimed Do not read the arrow as a normal input-output prediction. The claim is stronger: a whole input field is supposed to produce a whole output field for a named family.
Surrogate Modeling
topic · derivation		 new query -> fast stand-in -> approximate answer with a stated use range
  • new query
  • fast stand-in
  • approximate answer with a stated use range
 Speed changes what questions scientists and engineers can afford to ask. compare against the full solver on new cases near the edge of the intended use Do not read the fast stand-in as a replacement for the trusted solver everywhere. Speed is useful only inside the tested use range.
Uncertainty And Generalization
topic · derivation		 prediction + tested use range + failure evidence
  • prediction
  • tested use range
  • failure evidence
 A scientific model is dangerous when it is most confident exactly where it has the least evidence. move one important condition outside the training range and measure the first failure Do not read a confidence number as trust. Trust comes from testing the changed case the user actually cares about.
Neural Differential Equations
topic · derivation		 current state -> learned change rate -> next state
  • current state
  • learned change rate
  • next state
 It keeps the idea of continuous motion while admitting that part of the motion rule is unknown. run longer than the training window and check whether small rate errors accumulate into drift Do not read a short matched trajectory as a learned law. Small rate errors can accumulate when the system is rolled forward.
Symbolic Regression And Model Discovery
topic · derivation		 candidate ingredients -> searched formulas -> tested small law
  • candidate ingredients
  • searched formulas
  • tested small law
 A compact equation can be criticized and reused in ways a large fitted object cannot. remove a needed variable, add noise, or test a new experiment and see whether the formula still predicts Do not read a compact fitted formula as discovery. It must survive missing-variable checks, noise checks, and changed experiments.
Foundation Models For PDEs
topic · derivation		 many PDE tasks -> shared learned structure -> new task prediction
  • many PDE tasks
  • shared learned structure
  • new task prediction
 If it works, broad training could reduce repeated model-building for related scientific problems. hold out a new equation family, boundary type, scale, or rare regime and compare against a trusted solver Do not read broad training as coverage of a new equation. The new task must share the structure the model actually learned.
